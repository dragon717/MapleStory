# TMS273 研究与复刻工作包 v0.1

研究日期：2026-09-07。

这是公开资料研究结论、开发规格草案与八份可分派工单，不是独立子代理已完成的执行日志，也不是完整原作数据包。没有客户端、服务端程序、游戏素材或侵权分发内容。

先读 `00_RESEARCH_AND_REMAKE_PLAN.md`。来源URL、日期和证据边界在 `01_SOURCE_REGISTER.json`；39项有依赖关系的开发任务在 `02_BACKLOG.json`；已知与未知见 `03_FACTS_AND_GAPS.md`。

`04_DATA_CONTRACTS.md` 给出模块边界，`05_ACCEPTANCE_TESTS.md` 提供25项待执行验收，`06_OBSERVATION_TEMPLATE.json` 用于真实版本采样，`07_AGENT_DISPATCH.md` 是后续分派/汇总指令，`workstreams/` 是八份具体工单。

核心范围建议：先做一职业、一章节、少量地图与两个Boss，保留装备选择、核心进化、区域成长和可恢复的任务/奖励闭环；不要先追全职业、全地图、跨服拍卖与商城。

T＝台服同期证据，R＝跨区结构参考，P＝项目提案，U＝待核验，X＝目标时代之外的排除证据。任何未核定数值保持未知，不使用演示数值假装原作事实。
