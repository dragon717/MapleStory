# 验收用例 v0.1

以下均为待执行测试规范，不是测试通过报告。真实设备、延迟、人数与负载未确定，性能指标先定义再实测。

| ID | 场景 | 步骤 | 预期 |
|---|---|---|---|
| T01 | 新手主流程 | 空账号进入→接受目标→到地图→击杀→回交 | 无需口头提示可完成；每个阻塞有原因 |
| T02 | 任务满包 | 填满背包后提交带装备奖励的任务 | 不吞奖励；未到账不标已领奖；恢复后只领一次 |
| T03 | 任务重试 | 发送同一领奖请求两次并重登 | 奖励只有一份；返回确定状态 |
| T04 | 拾取竞争 | 两个角色同刻拾取同一共享掉落 | 恰一方成功，另一方收到明确失败 |
| T05 | 宠物竞争 | 玩家与宠物同时拾取同一物品 | 同一业务事实只到账一次 |
| T06 | 强化断线 | 扣费/结果提交时断开表现端并重连 | 费用和装备结果一致；动画不重算随机结果 |
| T07 | 属性移除顺序 | 不同顺序添加移除多个增益来源 | 最终回到相同基础状态，无漂移 |
| T08 | 同组增益回落 | 弱强同组效果并存→移除强者 | 按配置回落，不误删弱者 |
| T09 | 离场光环 | 增益来源退队/离图/死亡 | 按规则解除或保留；表现与属性一致 |
| T10 | Buff延长例外 | 给可延长和不可延长两类效果加延长属性 | 只影响允许类别，CD不误变 |
| T11 | 聊天焦点 | 输入包含技能绑定字符的聊天 | 不施法不移动，不穿透 |
| T12 | 模态交互 | 强化确认时点击场景/按战斗键 | 按约定拦截；Escape关闭优先级正确 |
| T13 | 平台边缘 | 在平台端跳跃、下跳、受击、转向 | 无越界/卡死/错误落地 |
| T14 | 梯绳门交界 | 攀爬、离梯、入门、切图连续操作 | 只执行一个合法状态转移 |
| T15 | 多段命中 | 同一施法多段攻击多个目标 | 段数、上限、重复命中规则正确 |
| T16 | 召唤消失 | 召唤到期/主人离场/地图结束 | 无幽灵伤害；资源被回收 |
| T17 | CD与预设 | 切换核心/装备预设并反复重登 | 不能通过切换非法重置CD或叠加永久效果 |
| T18 | 核心升级 | 升级指定核心再用对应和不相关技能 | 仅正确技能受影响；可追溯属性来源 |
| T19 | 练习隔离 | 完成练习Boss后尝试正式奖励接口 | 权威结算拒绝正式奖励，不只是UI隐藏 |
| T20 | Boss重连 | Boss死亡前后重连并请求结算 | 按资格确定一次性收益 |
| T21 | 周期边界 | 跨业务日/周、服务重启、补发重试 | 旧周期和新周期清晰，既不漏也不重复 |
| T22 | UI失败反馈 | 等级不足/钱不足/绑定/满包/次数不足 | 对应错误及恢复行动，非默默无响应 |
| T23 | 高密度可读性 | 多人/多段/召唤特效同时发生 | 危险预警仍可辨识；不以关掉全部信息为唯一解法 |
| T24 | 存档迁移 | 旧规则存档载入新规则并回放关键操作 | 来源事实保留；迁移可检查和回滚 |
| T25 | 第二职业接入 | 加入不同移动/攻击模型职业 | 不复制任务、奖励、属性和库存核心 |
