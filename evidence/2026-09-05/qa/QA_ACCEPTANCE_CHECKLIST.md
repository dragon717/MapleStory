# 独立 QA 验收清单

状态：3010 已实测；网络最终轮次等待 fresh QA DB 重启，浏览器已有部分 PASS/FAIL 证据；不继承 3000 首版结果。

## 运行门槛

- [ ] 开发明确可测提交/构建、`3010` 启动责任、健康检查和独立数据库路径。
- [ ] 确认 `protocolVersion`、`contentVersion`、登录/注册方式和测试账号策略。
- [ ] QA 不启动、重启或登出 3000 服务及唯一陪测 bot；不覆盖 `client/dist`。
- [ ] 每次实测记录服务地址、构建时间/标识、浏览器、视口尺寸和数据库标识；证据不写密码、token。

## 权威网络与并发

- [ ] 两个独立账号真实注册、登录、入图、互相看到，并确认角色归属来自认证结果。
- [ ] 伪造角色 ID、坐标、伤害、奖励/拾取字段、未知字段、非有限数、过长包和超频输入均被拒绝或限流。
- [ ] 输入旧 `seq`、跨账号操作和重复 `requestId` 不产生第二次移动、攻击、结算或广播。
- [ ] 两账号同时击杀/拾取同一掉落只产生一份权威结算；断线/重连、重复请求和服务重启边界按实际协议记录。
- [ ] 浏览器显示的坐标、HP/MP/EXP、怪物、掉落和背包状态均来自服务端快照/事件，不接受浏览器提交的结算结果。

## 地图与玩法

- [ ] 按当前 `shared/map.json` 的真实 foothold 链检查台阶边缘、墙/连接方向和可落地/阻挡边界；不把所有平台一律封边。
- [ ] 梯子/绳索可从正确接入点上下攀爬，退出后回到正确平台/动作，远端账号观察一致。
- [ ] 下方向键+空格只穿过允许的平台并正确落到下方平台；实体底地/禁止平台不穿透。
- [ ] 怪物使用同版资源的待机/移动/受击/死亡动画，移动、重生、普攻命中、接触伤害按来源规则运行。
- [ ] HP/MP/EXP 的减少、增加、死亡/重生边界和经验获取有服务端证据；来源不足的规则标为未验证，不补猜。
- [ ] 原表掉落、掉落归属/距离、服务器事务拾取和最小背包数据可观察；重复/并发拾取不重复结算。

## 原版视觉与响应式浏览器

- [ ] 使用真实原版素材的 HUD、数字、菜单入口和按钮；未把自创仪表盘或占位图当作 1:1。
- [ ] 桌面宽屏、横屏、窄竖屏分别打开：无横向溢出、关键游戏区域无遮挡、文字和按钮可读可操作。
- [ ] 运行时改变窗口尺寸后布局重新分组，不是整屏等比缩小；窄屏持续保留 HP、设置入口和聊天/聊天框内容，有空间再显示其他按钮。
- [ ] 角色脚点、foothold、墙/台阶、梯绳、怪物动画方向和 HUD 层级在浏览器实画面中复查。
- [ ] 记录加载失败、控制台 error/warn、断线/切图后的角色、计时器、监听器与音频清理。
- [ ] 右下动作按钮必须由列表/测试配置驱动：4 个一排、8 个一排、或按可用宽度自动分两排；保留源顺序/比例，运行时 resize 与窄屏不遮 HP、设置、聊天区域。
- [ ] 对 4/8/两排配置分别保存按钮 DOM 顺序、行数、边界/重叠测量和前后截图；不因当前 manifest 的固定按钮数量而把布局写死。

## 证据和缺陷格式

每次执行保存到 `evidence/qa/<run-id>/`：

- `run.json`：UTF-8；服务/构建/浏览器/视口/账号角色/执行时间/条目结果；不含密码和 token。
- `network.json` 或 `browser.json`：原始响应、快照/事件摘要、关键断言与失败时序。
- `*.png`：仅保存能证明布局、状态、溢出、落点或动作的截图；文件名带条目号。
- `console.log`：浏览器错误/警告和必要的网络摘要。

缺陷报告使用：

```text
[QA][P0-P3][条目] 标题
构建/服务/浏览器/视口：
前置与账号：
复现步骤：
预期（依据/版本）：
实际：
证据：
归属：后端 / 前端 / 协议 / 资源 / 待源核对
```

只有实际执行并保留证据的条目才可标记 PASS；未启动、来源不足或无法观察的条目标记 BLOCKED/NOT TESTED。
