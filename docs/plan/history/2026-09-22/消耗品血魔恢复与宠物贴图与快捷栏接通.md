## 结论

三件事里，**真正需要改代码的是 ② 血魔不恢复（store 存储路径）**；①宠物贴图是**派生产物过期**（manifest 里 `petUi.buttons.character` 被旧装配拍平）；③快捷栏消耗品**端到端早已接通**，此前“快捷喝药无效”实为 ② 在 store 路径无可见恢复所致。

## 做了什么

### ② 消耗道具恢复血魔（store 存储路径，`server/src/inventory_ops.rs`）

真实玩家（接 store）路径 `handle_use_item` 的 `use_item_with_max_mp(...)` 成功后：

- 之前：只 `arm_potion_cooldown` + `send_inventory_outcome`。store 事务本身会落库恢复血量，但内存 `player.state.hp/mp` 与快照要么没即时刷新、要么没有视觉确认（跳字）——用户看到“喝药不加血魔”。
- 现在：成功后重新 `store.load_profile` 并 `apply_profile_to_player` 落到内存状态（对齐无 store 的 fallback 路径）；计算**实际恢复量** `recovered=(Δhp,Δmp)`（`.max(0)`，满血喝药不出假数字）；只要实际恢复则 `emit_recovery_event(..,"potion")` + 显式 `send_snapshot`，让 HUD 与绿色跳字同拍刷出。
- 新增 store 路径验收 `server/src/consume_acceptance.rs::store_path_heals_world_state_and_consumes`：临时 sqlite store + `load_profile`(hp500/max1000) + 发放 `2009001`×3 + join + `Input UseItem`，断言 hp 500→550、数量 3→2、store 路径发出 `recoveryEvent(source==potion)`。

### ① 宠物贴图最近消失（派生产物过期）

根因取证（数据侧全部完好）：

- `client/public-tms273/assets/` 是 **gitignored 派生产物**，非源码；`resources/tms273-export/` 同理。`scripts/export_tms273_*.cjs` 与 `scripts/assemble_tms273.cjs` 是唯一权威源头。
- 宠物精灵数据/文件一直正确：`manifest.pets` 990 真宠物（13,264 帧 PNG 全在磁盘）；`petUi.buttons.character` 中间产物 `pet-ui.json` 是完整 `{normal,pressed,disabled,mouseOver}`。
- 消费侧：HUD `createPetButton()` 读 `manifest.petUi.buttons.character.normal`，世界宠物精灵、宠物管理窗（`panel.ts` `setArt`/`renderSelected`）读 `manifest.pets.<id>.stand[0]` 与 `.icon`——本地无加载错误，均按正确形状写。
- 结论：旧装配出的 manifest 把 `petUi.buttons.character` 拍平（缺 `.normal` 等键）⇒ HUD 宠物按钮（打开宠物窗的入口）读不到而**不创建** ⇒ 表现为“宠物的贴图不在了”；`check_tms273_runtime.cjs` 断言 `buttons.character.normal.url` 正是为抓这类平拍。重跑 `node scripts/assemble_tms273.cjs` 刷新派生物，现 `buttons.character = {normal,pressed,disabled,mouseOver}`、`pets=1002`（含 8 位别名）、门禁 PASS。

### ③ 快捷栏消耗品

端到端全部既有，无需新增客户端代码：

- 模型：`keybindings/model.ts` 有 `{type:'item', itemId}`；绑键窗“消耗品”页只列类 2 且 `quantity>0` 库存项。
- 渲染：HUD 快捷栏 `updateShortcuts` 给 item 绑定显示图标 + 实时数量。
- 激活：键盘（`player/input.ts` L318 `useItem(itemId)`）与点击（`hud/view.ts::shortcutClick → options.activateBinding → main.ts useShortcutItem` → `{type:'useItem', inventoryType:2, sourceSlot, itemId}`）。
- 此前“快捷喝药看不到回血”＝ ② 的 store 路径无恢复反馈；②修复后快捷消耗网络通路即正常。
