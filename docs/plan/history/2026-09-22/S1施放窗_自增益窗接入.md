# S1 施放窗：自增益窗接入（窄口径）

- 日期：2026-09-22
- 用户指令：按 `docs/plan/PLAN.md` 三优先项推进；经确认选缺口 A（S1 施放窗）并定了**窄口径＝只做自增益窗**（负面状态窗 / 召唤存活归后续）。
- 前置：四支柱唯一权威 `mechanics.rs::AttackPlan::of(level)`、`player_status.rs` 既有唯一时钟、`check_tms273_damage_pipeline.cjs` 门禁。

## 结论

`time` 机制字段的「未实现」语义从**整组**收窄为「**自增益施放窗已实现**、负面状态窗 / 召唤仍未实现」；把 `1221052 神之滅擊` 端到端接入 `PHYSICAL_AREA_ATTACKS`。其余 8 条被 `time` 挡住的物理线攻击技能仍被挡。内容版本 `tms273-38 → tms273-39`。

## 做了什么

1. **Phase B（唯一入口派生）** `server/src/mechanics.rs`：`AttackPlan` 新增 `self_buff_window_ms: Option<u64>`，`AttackPlan::of(level)` 从 `level.time`（秒）`.filter(>0).map(×1000)` 派生。这同时提供门禁 §3g 对 `level.time` 的**读取点**（「宣布已实现」必须有消费点撑腰）。
2. **Phase C（接线，仅 1221052）** `server/src/world.rs` 新增 `SKILL_GODS_ANNIHILATION`，`PHYSICAL_AREA_ATTACKS` 37 → 38；`server/src/skills.rs` 的物理 generic 臂在 `cast_elemental_area` 后，若 `AttackPlan::of(&level).self_buff_window_ms` 有值则 `player.status.apply_buff(other, window_ms, self.tick, Release::None)` —— 复用 `player_status` 唯一时钟，到期由 `world.step()` 里 `advance()` 既有清理点自动收回（`Release::None` 无附属状态要收）。
3. **Phase D（门禁重构 + 客户端镜像）**
   - `scripts/check_tms273_damage_pipeline.cjs`：`PHYSICAL_MECHANISM_FIELDS` 删 `time` 行、`updatableTime` 理由改措辞；`PHYSICAL_MECHANISM_GROUP` 删 `time: 'buff-window'`；§3g `IMPLEMENTED_MECHANISM_FIELDS` 加 `time`；新增 `NEGATIVE_STATUS_TIME_ATTACKS` 人工豁免名单（沿 `PHYSICAL_ONE_TURN_ATTACKS` 先例）把 `1121015 烈焰翔斬` / `3121052 波紋衝擊` / `4121017 挑釁契約`（`time` 是 burn / 负面 / 挑衅状态窗）仍挡在表外；双向断言 `1221052` 必须进期望集、负面 3 条必须不进。
   - `client/src/features/skills/view.ts`：`ACTIVE_SKILLS` 物理线名单补 `'1221052'`（§3f 客户端镜像与服务端逐项相同），注释更新。
4. **Phase E（验收）** `server/src/mechanics_acceptance.rs` 新增两条：
   - `mech_self_buff_window_opens_and_expires_exactly`：施放 `1221052`（玩家等级 200，过源 `requiredLevel:160` 的 Hyper 门槛）→ 自增益窗立即出现、剩余整 10 000 ms（`time=10` ⇒ 200 拍）→ 推进 200 拍到点由 `advance()` 精确收回、`buff_map()` 不留尾巴。

5. **版本与装配器**：内容版本 `tms273-38 → tms273-39`，五处手写落点全同步（`shared/protocol.ts` / `server/src/protocol.rs` / `scripts/assemble_tms273.cjs` / `check_tms273_runtime.cjs` / `check_colossus_live.cjs`），重跑装配器（`maps: 211 / assets: 120556 / npcs: 395 / missing: []`），派生 `shared/*.json` 与 manifest 跟上；协议版本 34 未变。

## 关键纠缠（决定窄口径）

`time` 有**三种语义**：自增益窗 / 负面状态窗 / 召唤存活时长，源无法自动区分。删除 `time` 的「未实现」记录会自动解锁 4 条：干净自增益仅 `1221052`；负面 `1121015/3121052/4121017` 靠人工豁免名单单独挡回；其余 5 条仍因孤立 `prop` 或 `subTime` 被挡（`騎士密令/神聖衝擊/神聖烙印/追隨者衝擊` 因 `prop`，`箭座 3111013` 因 `subTime`）。
