# TMS273 现金商店系统复刻（2026-09-13）

## 范围与结论

复刻 TMS273.7 現金商店（CashShop）核心链路：分类页签、商品网格列表、商品详情（图标/名称/单价/期限/条件）、购物车与购买结算、余额显示与 GM 充值。协议 **17→18**，内容版本 **tms273-16**。前后端同改，**需用户跑 `zsh 启动3010.command` 一起换版本后实玩**（协议变更，不能只换客户端）。

## 数据链（新导出器 `scripts/export_tms273_cashshop.cjs`）

- 源权威：客户端 WZ `Etc/Commodity.img`（12617 条）+ `UI/CashShop.img`（窗口布局/页签美术）+ `String/{Eqp,Cash,Ins,Consume,Pet}.img`（名称）。参考端 `Etc/OldCommodity*.json`（28 类旧商城表）仅作分类语义旁证，**不作为数据源**。
- **SN 9 位前缀即分类编码**：110 人气、120–150 活動、160 時裝（服装细类）、170 寵物、180–190 道具、800 兑换券、920 里程类。`OnSale=1` 共 1491 条；SN 900/910 是楓點充值/楓幣兑换 SKU（无 ItemId），**排除不进在售表**（`itemId < 9000000` 断言钉住）。
- **源边界**：39 个在售商品在客户端包内无美术（退役商品仍挂在在售表）→ 按"素材不存在"排除并记录，不伪造图标。最终导出 **1452 条商品 / 1349 个图标**，名称经 String 表 + Item/Pet 包内联 `name` + items.json/pets.json 种子三层补齐。
- 图标路径家族（节点名两种形态都要试）：装备 `Character/<族>/<8位>.img/info/icon`；宠物 `Item/Pet/0500.img/<8位填充>/icon|info/icon`；现金消耗 `Item/Cash/<0xxx>.img/<8位填充>/icon`；伤害皮肤/910xxxx `Item/Special/<0xxx>.img/<非填充>/icon`。
- 产出 `resources/tms273-export/cashshop.json`（categories 8 类 + commodities + itemNames + itemIcons + ui 页签美术）；`assemble_tms273.cjs` 断言 >500 条、8 类、SN 无重复，把目录内嵌进 `shared/gameplay.json::cashShop`、美术进 `manifest.cashshopUi/cashItems`、`client/public-tms273/assets/cashshop.json`（客户端运行时 fetch）。

## 服务端（`server/src/cashshop.rs`，world `#[path]` 挂载）

- **钱包**：`Profile.cash`（SQLite `player_stats.cash` 列 + 既有 ALTER 迁移模式）；授予路径只有 GM `/cash <数>`（1..=1e9），购买先扣款再入包，失败任一半段不落账。
- **购买**：客户端只报 `{cashBuy, requestId, sn, quantity}`；商品、单价、堆数、每条售卖条件（OnSale、price>0、reqLevel、reqPop、gender）全部服务端解析。price=0 的兑换目录行永不可购（`cash_not_purchasable`）。
- **幂等**：`cash_requests: BTreeMap<(player,requestId), CashOutcome>` 有界窗口（64×人数），重放原回执不二次扣款（与 party 同型）。
- 入包走 `inventory::add_items` 克隆背包原子校验（现金页签），存档事务写背包+profile。
- `inventory::inventory_type` 兜底分支加 `checked_div` 防御（本目录 910xxxx 等非 6 位 id 不再 panic）。

## 客户端（`client/src/features/cashshop/`）

- `view.ts` CashShopView：源 `CashShop.img` 侧栏 8 页签（主頁/活動/轉蛋/強化/遊戲/美容/時裝/寵物/套組/搜尋 中在售的 8 类）、商品网格（priority 排序）、详情面板（图标/名称/单价楓點/期限/购买条件）、购物车（增减数量、合计预览、逐行提交 `cashBuy`）、余额条、`cashState`/`cashBuyResult` 回执处理；开窗即 `cashOpen` 要权威余额。
- 入口：MENU 窗操作区「現金商店」条目（`MenuView` OPERATIONS cashShop + `onCashShop` 回调）。
- `style.css` 响应式（窄屏单列、触控目标 ≥36px）；数据字段：`sn/itemId/name/tab/price/count/period/gender/reqLevel/priority`。
