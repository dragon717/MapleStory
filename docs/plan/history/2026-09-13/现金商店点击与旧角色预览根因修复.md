# 现金商店点击与旧角色预览根因修复

## 根因与修改

- `#game-shell>#ui-windows` 设置 `pointer-events:none`，现金商店根节点未覆盖继承，所有鼠标操作穿透。`cashshop/style.css` 补 `pointer-events:auto`，恢复分类、详情、直接购买、加购和结算点击。
- HUD `CashShop` 仍是未接入分支。HUD 的「商店」与菜单现金商店共用 `openCashShop`，开窗同步当前完整角色并释放移动/持续施法；游戏输入与交互阻断包含现金商店，断线关窗、退回选角销毁监听器。成功消息也保留正常状态，不再全部标红。
- 只读核对用户 `muniao`：脸型 20000、发型 30020；目录有 base/hair，却无 `face:20000`，`composeAppearance` 因脸型缺失返回 undefined。旧检查只用当前创建选项，且离线宿主没有真实父层事件样式，未覆盖这两个触发条件。
- `export_tms273_avatar_parts.cjs` 现在在 MakeCharInfo 之外显式纳入既有默认纸娃娃 `DEFAULT_SOURCES` 的脸/发。同版 `Character/Face/00020000.img`、`Character/Hair/00030020.img` 已重新导出两性别动作层并装配；不改角色外观存档、不用替换脸型掩盖缺项。商店为其它缺目录的旧角色保留与世界一致的完整纸娃娃兜底；真实试穿仍需该角色分层资源。
- 内容升级 `tms273-19`（协议仍 19），同步 Rust、TS、装配和检查默认值。生成资源位于 `resources/tms273-export` 与 `client/public-tms273`，由导出器负责可再生成。
