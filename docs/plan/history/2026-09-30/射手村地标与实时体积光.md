# 射手村地标与实时体积光

用户纠正首版不是射手村，要求参考旧三维射手村和巨石之约保留交互/UI，并增加优秀光影与丁达尔效果。主代理亲自实现模型与渲染；GPT-5.6 Luna / max 只读核查交互和删除依赖。

## 实施范围

- 查看本地 TMS273 `100000000` 完整原图（`artifacts/henesys/tms273-source.png`）；复用旧模型脚本里的蘑菇屋造型函数，移入当前曲线建模脚本，不恢复旧加载器。十处地标包括西侧蘑菇塔、市场屋、公园石门、风车和弓箭手大厅。建筑纵深与台地仍为用户授权的曲线解释，不声称原地图1:1。
- 删除当前建模管线对通用中世纪村屋组件的依赖。保留已有 CC0 植被，补充第二排绿树和背侧地面，模型从首版28.86MB降低到约13.75MB。源 `.blend`、GLB和预览仍在 `resources/scenes/henesys/rail-v1/`。
- 实时单次散射沿相机视线采样场景深度和太阳阴影，树冠真实遮挡产生光束。散射半分辨率计算，合成保留全分辨率深度；透明原版角色与名字最后绘制，不被色调映射和雾染色。太阳阴影包围盒沿角色所在路段移动。
- 恢复五条原图梯子的位置、长度和梯子/绳选择字段；端点跟随新主路高度，新增五个28px厚的高台。服务端按平台ID派生厚度，避免把上层平台做成720px厚、堵住下层道路；2D与3D均显示同一梯子和平台。新小地图同时显示高台和梯子。
- 射手村活动卡补上省电画质与键盘设置；移动/跳跃/战斗/NPC/任务/背包/聊天/地图继续用原 World、DOM UI 与权威服务端。
