# 初弦地东边村落正式实装

日期：2026-09-30。用户授权替换旧3D初弦地，进入真实游戏世界，并增加WebGL体积云、体积雾、太阳、光照及丁达尔效应；最终通过根目录 `启动3010.command` 验收。阶段政策不变，未启动独立QA。

## 实现

- 复用已经确认的东村 Blender 源与GLB：`resources/scenes/chuxian-east-v1/models/`；本轮没有重建模型或覆盖历史源。422对象的既有Blender场景通过MCP状态/场景/截图核对。
- `scripts/build_chuxian_east_layout.cjs` 从模型同源布局生成 `shared/chuxian-east.json`：16条路线、225段权威道路、19处路口。道路空间标高1.8～27米，三处环路以及主路、坡道、溪岸、背巷沿原设计落地。
- 地图身份仍为 `100000000`，统一名称「初弦地」。装配器同步脚点、29个原版NPC、传送门、反应物、怪物出生点和空间小地图；NPC身份/业务保留。旧弧形单路模型退出加载，旧发布GLB/小地图/封面由装配清理，历史可编辑源保留。
- 服务端拥有路线行走、路口选择、跳跃与保存坐标修复。客户端仅接收方向/跳跃输入；从旧场景保存的位置安全回到新出生点，新路线位置重连保持。沿路距离用隔离弧长区间，跨路仅在共享路口切换；当前不是任意草地自由行走。
- 原版World继续拥有角色、NPC、动画、技能、宠物、掉落、任务与交互；Three逐帧投影原显示对象，渲染后恢复玩法坐标。像素层使用深度合成，保留原UI。NPC点击用同一镜头投影匹配原版对话入口。
- 默认固定FOV38°/俯仰0.24rad，跟随真实标高；脚点被地形遮挡时有限抬升取景，近身遮挡的建筑/摊位淡出。右键微调角度，滚轮缩放，活动窗口可恢复镜头或切换2D/省电。
- WebGL2三维噪声体积云、依场景深度截止的高度/溪岸雾、太阳阴影约束的单次散射光束、PBR环境反射、暖阳/冷色填充光与HDR柔光。体积采样为32步，省电模式跳过体积后处理；未使用全景图替代几何。
- 已联网下载 Poly Haven `qwantani_dawn_puresky_1k.exr`（Greg Zaal / Jarod Guest，CC0），用于环境照明。太阳来自Three物理天空，云/雾为程序体积。下载来源、许可、大小和SHA256保存在 `resources/scenes/chuxian-east-v1/vendor/lighting/source.json`；原有树木素材继续复用。
