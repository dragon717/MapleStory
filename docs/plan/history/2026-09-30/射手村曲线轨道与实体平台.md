# 射手村曲线轨道与实体平台

## 已实现

用户确认「沿路线自动处理纵深」：左右走与跳跃保持卷轴操作，2D 纸娃娃沿半径 85m 的弯曲路线显示，相机随局部路线转向。此任务授权改变射手村布局与平台交互，覆盖旧版纯视觉替换约束。

- `shared/henesys-rail.json` 统一 21 段平台、50px 台阶、720px 实体厚度与曲线坐标。服务端处理侧面阻挡、顶头、落地及禁止穿台；没有新增客户端移动状态机。
- 装配器替换射手村碰撞与小地图，并将 29 个 NPC、传送门等对齐新台地。保留身份和目的地；存档登录保留可用横向位置，脚点对齐新地面，不修改账号数据库。
- 2D 显示切换使用同一新台地，不再渲染位置已不一致的旧背景。战斗、任务、NPC 点击仍走原 World。
- Quaternius CC0 Nature/Village 现成素材组成树草石与 5 栋模块房屋；地形由 Blender 生成。来源见 [素材说明](../../../technical/Henesys_rail_assets.md)。当前 GLB 28,857,176 字节，180 个来源标记对象，贴图嵌入；`.blend` 与预览位于 `resources/scenes/henesys/rail-v1/`。
- 删除旧 prepare/build/refine/export 四个射手村建模脚本，以及旧模型、Blender 备份和预览；旧公开 `henesys.glb` / `overview.png` 已移除。TMS273 原始导出、其他场景和历史记录保留。

## 用户待验

当前是可玩的第一版地形与美术组合，不能把结构与定向检查通过视为参考图质感已达标。需要实际确认跳台手感、角色尺寸、镜头转向、童话感及远景密度。完整在线任务/战斗流程未复验。

推荐表述：**曲线轨道式 2.5D 平台跳跃：2D 纸娃娃、3D 实体台地、沿路线自动变化的纵深、跟随局部切线转向的摄像机。** glTF 使用 Y 为高度、Z 为纵深；Blender 使用 Z 为高度，表达需求时直接说「高度/纵深」更清楚。
