# 射手村前景清晰度与 3D 建模指南

用户要求沉淀 3D 场景开发经验、登记调用别名「3d建模」，并反馈 3D 射手村里的 2D 显示与文字不清楚。Astra 负责渲染链、修复和集成；Luna / max 仅整理通用指南初稿，主代理核实并补充本次结论。

## 根因与修改

入口为 `World.create()` → `HenesysView.create()` → `draw()`。原版 2D 相机为 1，射手村 3D 把同一前景缩到 0.75 后栅格化，再将画布贴入 Three 平面并放大；`LinearFilter` 再次混合已有像素。最终 Three 像素比上限 1.5，在 DPR=2 屏幕上又少于显示器像素。NPC 自带的 `resolution: 2` 也无法恢复中途损失的笔画。

- `world.ts` 保留源相机缩放 1，覆盖同一画布中的角色、NPC、姓名、任务标记和其他前景。原版 2D 保持原行为。
- `henesys/view.ts` 对已经栅格化的前景使用最近邻过滤；DPR 上限改为 2，并在屏幕像素比变化时更新缓冲尺寸；前景禁用雾，继续关闭色调映射。环境模型仍使用自己的材质与过滤方式。
- 镜头范围、服务端坐标、碰撞、纸娃娃资源和 DOM 窗口未另造实现；点击仍用射线 UV 回投到原 Phaser hit test。
- [`3D场景开发通用指南`](../../../technical/3D场景开发通用指南.md) 总结参考、尺度、MCP、资产持久化、混合渲染、输入与生命周期。技术索引与根 `AGENTS.md` 登记大小写不敏感的别名「3d建模」，后续用户提到时先读本文档；未安装全局技能。
