# 初弦地路口头顶方向提醒

用户要求角色到十字路口时，头顶出现原版贴图动画，上路显示上箭头、下路显示下箭头、双向同时显示。主代理完成核心；GPT-5.6 Luna / max 仅只读核查TMS273源素材，没有独立QA。

## 实现与素材

- 复用现有清单`miniMap.icons.direction.n/s`：源`UI/UIMap.img/MiniMap/iconDirection/n|s/0`，实际Canvas为`UI/_Canvas/UIMap.img/MiniMap/iconDirection/n|s/0`，20×18。源四帧均链接同一Canvas，属于静态箭头；本次以原图加±3像素轻微浮动实现提醒动画，没有冒称原素材为多帧动画。原版Basic的BtUP/BtDown只有12×12单帧状态，此处采用已有更清晰的箭头，不另增导出、版本或依赖。
- 显示判断对应服务端`henesys::turn`的55像素路口范围、方向分数门槛、节点/邻边顺序及当前道路胜出的排除逻辑；分别检查上、下，仅提示实际可选分支。Rust解码与快照序列化在路线端点存在一个ULP差异，客户端显示判断用1e-7像素容差避免漏箭头；生产服务端路由未改。
- `World`用权威自身位置决定可用方向；`PlayerView`用同帧插值位置和当前纸娃娃头顶锚点绘制，沿用现有3D投影和高分屏像素采样。一个根容器、两个复用纹理，双向并排居中。只显示自身提示；离开路口、空中、椅子、死亡或贴图缺失隐藏；离图销毁，没有额外计时器或监听器。输入、快捷键、对话与传送逻辑沿用上轮。

## 必要检查

- `cd client && node src/features/henesys/junction.check.mjs`通过：调用真实Rust `turn`测试输出，519个位置对照上/下/双向/无提示及±55边界；实际显示方法检查单/双居中、浮动、根复用、非整数角色锚点、远端/空中/椅子/死亡/缺图隐藏。
- `npm run typecheck`、`git diff --check`通过；统一入口的tsc/Vite及Rust配对构建/资源校验通过。
- 主代理在正式`World`和`HenesysView`隔离预览里发送正常快照，检查上/下/双向/无提示及空中隐藏，原图均20×18、DPR2、零脚本异常；人工查看截图确认双箭头在名字上方。截图：`artifacts/henesys/east-village/live/junction-hints.png`。浏览器为软件WebGL、简化光照，未声称原生GPU性能或联网实玩验收。
