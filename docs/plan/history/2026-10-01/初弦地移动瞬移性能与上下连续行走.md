# 初弦地移动瞬移性能与上下连续行走

日期：2026-10-01。用户要求根因修复移动/瞬移卡顿，并让上下键选择路径后继续沿路行走。主代理拥有实现与必要验证；GPT-5.6 Luna / max 两项只读辅助核查调用链、计算与渲染瓶颈，没有独立QA。

## 根因与修改

- Phaser→Three 的两张整屏 CanvasTexture 每帧跨 WebGL 上下文上传。改用共享 WebGL2 上下文、Phaser RenderTarget 与 Three ExternalTexture；角色颜色直接留在GPU，深度矩形通过实例绘制到GPU目标。帧缓冲随尺寸调整；销毁三维视图保留共享上下文；角色/文字仍按完整DPR2与最近邻合成，不经过环境调色。
- 静态树木/建筑阴影每帧重复绘制。2048阴影保持，只有局部8米覆盖单元改变时刷新；缓存地形面和局部遮挡候选，避免遍历全森林射线检测。体积云/雾两段32步与太阳遮挡保持，平滑大气通道四分之一尺寸、Bloom半尺寸；场景、深度和角色完整分辨率。
- 纸娃娃每次动画换帧销毁/新建全部Image。复用现有Image，只改纹理/位置/翻转/颜色，部件减少时销毁多余对象。运动样本仅在新快照到达时observe，渲染帧只advance/render；静态地图路线DOM只在换图时更新。
- 190/295像素技能瞬移低于600像素距离阈值，误被插值成滑行。复用已去重的权威skillCast与portalResult，清除目标轨迹，使下一份权威坐标直接显示；普通走路继续插值，无客户端坐标预测。
- 服务端移动每步同步保存完整角色档案。纯位置改为同一步单个SQLite事务/缓存语句写入，仍每步持久化；关键属性/物品保留即时完整保存，任一行失败整批回滚，活动内保留返回点。
- 每名观察者重复序列化同图所有角色。每步按地图只序列化一次角色数组，观察者自己的NPC/任务/selfId等仍独立生成；巨像距离可见性继续按观察者计算。关闭/已满输出跳过无用快照计算，保留原离线驻留规则。
- 上下键可沿当前道路行走，到路口选择匹配分支后保持弧长方向，离开入口前锁定路口，避免持续持键来回换路；左右仍可沿路。瞬移在实际路线内推进/环路绕回/开路端点截断，保持跳跃相对路面高度，空中不切换支路；计划保留实际技能请求方向。所有换图/复活入口共用清理这四个路由状态，防止旧方向与冷却残留。交互仍是独立可配置共键。

同一Apple M3 Pro原生ANGLE Metal、1000×700 CSS、DPR2、默认全部光照效果，实际World接收20Hz协议快照，120个行走渲染帧：

| --- | ---: | ---: |
| 3D draw GPU段均值 | 53.40ms | 7.34ms |
| 3D draw GPU段P95 | 93.82ms | 12.21ms |
| 32人真实World.step+SQLite均值（debug，40步） | 124.54ms | 4.63ms |
| 同上P95 | 134.78ms | 6.05ms |
