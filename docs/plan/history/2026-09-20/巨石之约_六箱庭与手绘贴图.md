## 已实现

- 第三活动继续使用现有账号、角色和 WebSocket。Three.js 负责真实三维空间、2.5D 轨道视角及面片人物；原版世界仍为 Phaser，往返恢复既有宿主。Rust 顺序 World 决定移动、碰撞、跳离／落地、NPC、通路、桥与公共苏醒事实，未加入玩家预测。
- 六个分区：蓝旗港湾、层檐街区、回潮海岸、望潮高地、肩背聚落、背风梯园；13 条轨道、36 个成对路口，总长约 4.6 km，包含环道、上下层支路及移动巨像局部道路。路口按原版 ↑ 操作；服务端选择最近合法路口并保留连续输入、速度和朝向。各区有实际可走道路和三维环境，但这些长度与地形**不代表六个完成内容制作的巨大箱庭，更不代表十小时内容**。
- 港口保留快跑的小石头人与慢随的大石头人、缺口跳跃／下层绕行、攻击断藤、船工控盘放桥及 NPC 过桥。放桥期间与落稳后的对白区分；孩子与补网人的近景回应只在镜头返回且人物确实到场时出现。拾网梭和船工控盘、交替步态原图已接入。
- 海中礁石与苏醒后的手掌是同一组几何。镜头先看手，再拉远看巨像，最后回到操作；迟到／回看显示当前公共事实，不倒放世界。手掌停稳后可登上移动肩部，分区根据当前位置与邻近路口按需装载，最多保留当前及一个邻区。
- 3D 建筑、道路、巨像、云层使用新增原始手绘纹理；石材、木材、屋瓦、灰泥、草地、云六图，人物动作四图。港湾环路移至港口后方，避免陆地挡住“礁石就是手”的揭晓；高台装饰建筑移回码头岛，建筑基座延伸至地形内部，修复悬空。
- 原先开场可达的神庙外廊已移除。神庙位于**巨像体内、故事中段约十小时后**，本轮不添加外部入口或等待十小时的计时门。

## UI 与交互

遵循用户新增最高优先级要求：**复用复刻冒险岛 UI 与交互；另立规范需用户明确确认**。移除巨石场景独立按钮条和帮助层，保留现有 HUD、聊天、快捷栏、任务追踪、小地图、地图目录、世界地图和键盘设置。

- 活动清单使用已导出的 UtilDlgEx 框体、既有对话选项样式和源关闭按钮，接入共享拖动／置顶／缩窗约束。演出回看、跳过、视角、省电档、返回和帮助均放在现有第三活动条目中。沿用非模态窗口语义，隐藏按钮不会进入正常 Tab 顺序；关闭恢复游戏焦点，打开按键设置不抢焦点。
- 小地图使用现有框体、角色／NPC／路口图标。世界地图的 M、菜单及小地图入口共用一个现有窗口，显示原创轨道地图数据（P 类内容，并非伪造 TMS 原地图）。只查看邻区，不提供任意传送。窄屏保留原尺寸按钮命中区；退出活动时，已打开地图正确恢复当前普通地图所在页。
- 点击人物、↑ 或原有交谈键进入既有 `NpcDialogueView → npcTalk → npcResult` 链路；距离、人物 ID 和步骤由服务器校验。NPC 对话共用原版窗口关闭与焦点逻辑，不另建交互协议或专属对话皮肤。
- 原版背包、技能等界面可查看，不代表它们的全部玩法已移植到三维活动。未实现的旧地图动作由服务端活动边界拒绝；当前主要操作为移动、跳跃、普攻、交谈和路口通行。

## 后续制作边界

**当前美术未达到用户要求的高水平冒险岛／风铃岛统一观感。** 已有手绘纹理与人物原图，但巨像仍是粗轮廓组合，肩背地形过于规整，植被／建筑重复、海面泡沫和水幕仍需构图与形态制作；不能用编译通过或概念封面冒充终版实机。箱庭需要后续地标、生态、NPC 日常与任务内容，不以扩大轨道充当内容完成。

水面为解析大波、世界空间泡沫和局部几何水幕。权威水位固定 -5 m，仅用于安全回落边界；视觉浪峰不参与碰撞和浮力，游泳尚未实现。巨像具有起身与有限平移／转向，不代表完整远程迁徙行为。统一显示时间和局部参考系已贯通，玩家预测未获授权，服务器往返延迟仍会影响手感。

实体低端 GPU、真实音响、长期运行／热稳定及高延迟丢包环境未验证。服务器重启保留公共桥／苏醒事实，但活动成员回到原地图持久位置；仅会话驻留断线回接保持活动身体。
