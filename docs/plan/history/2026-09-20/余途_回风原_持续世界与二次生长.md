## 持续运行与二次生长证据

- 无人介入时，原有修桥日程按首次进入触发继续；首运后日常生活每 5 秒结算、同车往返，不要求玩家保持在线。短缺等待林圃再生和运输，货到后仍可反复休息、战斗、练翼与重访。库存守恒检查覆盖一小时模拟和中途消耗。
- 两岸仓各上限 12，车辆上限 4；单次离线补算上限一小时／720 步，更久视为休息并保留库存／货物。时钟倒退不重复推进；写库失败保留旧事实并 5 秒后重试，不每帧重写车位。
- 材料共享 `Material::heat`：先失水、后燃烧。旧干枝产生热流；新湿纸逐层干燥，火盆在干纸时停止接受加热。槐生在安全且有补给时自己烘纸；玩家可以帮助，或使真实蜗牛离开石台后等待。新增情境没有第二套任务、碰撞、数据库或战斗引擎。
- 原记录缺少 `life` 与个人新字段时使用默认值，不重复发首批货。隔离 SQLite 检查恢复、强制事务失败、重复行动、重开后个人帮助和公共纸页一致。晚到者能读干纸，不获得别人的帮助记录。
- 每角色成功行动序号持久化；最近 64 条回执精确重放，更早请求由序号拒绝，运行时缓存上限 256。70 次行动后截断回执并重开数据库，旧请求仍不能重新扣资源。
- 岚织教授叶翼后，原岛与公共渡口复用同一移动修正；再次展开不能延长当前起落的时限。原根道、树桥、热流检查继续通过。

## 素材与剩余边界

当前运行是分层 2D Phaser。TMS273 地面、火、绳桥、怪物和角色素材继续属于原有来源；本轮不把改名当作原创授权。新槐生、阿苇步态通过 imagegen 生成，原图保存在 `resources/characters/windbell/images/`，原样原子复制到 `client/public-tms273/assets/windbell/`；脚点与比例由 `maps.ts` 元数据表达。`prepare_windbell_runtime.py` 包含可复用装配步骤，本轮仅执行新增文件复制，没有重跑并覆盖旧资源。

新增三张 PNG 都是 1024×1536 RGBA。槐生采用 `npc-huaisheng-fresh.png`（SHA256 `375dbf8b459e4275cdfe38eaed7ec6e843a27f0e1dd4cf021474dc6fc7740102`）；阿苇两帧分别为 `npc-awei-walk-1.png`（`1f16f4c87ede7176a494ee6450d19d16644ea8a5a98d3613a714fcbe707d9dfc`）、`npc-awei-walk-2.png`（`ba95f5204e01c1861a2851dbbb93bf6200d55b57c0cc3d38a989c603deece1e1`）。这些资源按仓库既有政策被 Git 忽略，其他机器需同步本地内容资源；没有把忽略文件冒称已进版本库。

alpha 检查区分了透明像素隐藏 RGB 与真实边缘；槐生有极低透明度残留，最终缩放观感、阿苇两帧连续性、动作手感与声音均待加载亲测。搬运、递纸和烘纸没有专用人物动作，当前由位置、物体／纸面变化和声音表达；不称为全动作完成。原岛仍是个人练习实例，公共渡口共享；不是整个世界全共享的迁移。

更深天命权柄、经验球与觉醒人格、跨地区贸易、天气、多区域生态不在本轮已实现范围。新内容应继续复用现有材料、行动、有限记忆、地图与制作路径；真正新机制再增加明确领域规则。本轮工程基线及真实扩展已交付，在线加载、真实表达与“是否值得回来”的结论由用户实玩给出。
