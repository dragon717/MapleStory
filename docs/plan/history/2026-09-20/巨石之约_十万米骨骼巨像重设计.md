## 本轮落实

- Astra 亲自通过 Blender MCP 制作真实 Armature 与刚性蒙皮：48 根骨骼，其中双手五指各 3 节，共 30 根指骨。头、躯干、肩肘腕、髋膝踝均有独立骨骼。方体大块叠小块，石块只归属一根骨骼，关节弯曲不拉软石头。可编辑源：`resources/scenes/colossus/redesign/models/colossus_rigged_100km.blend`，当前场景 `CR_Rigged_100km`；运行模型 `colossus-rigged.glb`。
- 中立姿态实际高度 100000.00098 m，玩家标尺 2 m。旧可见单栋房屋／人形的全身概念图比例被否决；同文件其他旧源场景及平掌预览只保留追溯，运行时不再加载独立静态手掌。
- 手型自然垂放，手臂、手腕、手指能弯曲。程序按稳定骨名控制；`shared/colossus-rig.json` 从 GLB 导出父子关系、休止姿态和弯曲范围。当前 Rust 示例按局部 X 轴弯曲驱动头、躯干、右臂／手腕／五指；资源本身保留完整四元数骨骼能力。尚未制作完整走路、攀援承载动作库或通用姿态编辑器。
- Rust 使用同一骨架计算承载区域姿态、跳离／落地速度，快照下发骨骼姿态与分区变换，Three.js 插值网格和乘员。默认无玩家预测。指岸挂到 `index.3.L`，肩背分别挂到 `clavicle.L`／`chest`。
- ↑↓ 攀爬、松键悬停、底部向下回高台，复用原版梯子人物动作；攀到终点按 ↑ 通过既有箱庭路口进入肩部，随后仍可跑跳和走其他区域。路线约 40 m，**不是完整数十公里攀登路线或十小时内容**。原平掌停稳后登岸方案已失效。
- 植被采用 Kenney Nature Kit 的免费 CC0 网格，不自建树／草／花；保留来源与许可证，重新绑定手绘材质。来源：[Kenney](https://kenney.nl/assets/nature-kit)，本地 `resources/scenes/colossus/redesign/vegetation/vegetation-sources.md`。材质与参考图原始字节、生成提示词保存在 redesign 的 textures/concepts 目录。

## 实画面发现并修复

1. 进入港口时前景房屋挡住角色：建筑／树木不并入整区静态批次，沿既有视线检测淡化遮挡。
2. 巨像表面跨公里铺一张图导致近看缺细节：运行时按米级重复手绘纹理；增加远海面以避免全貌镜头露出小海面边界。
3. 长按 ↑ 到攀爬终点后不能过路口：通行点移到真实轨道末端；石质手脚点嵌入指壁，小歇脚台高度对齐落点。
4. 肩背路线悬在模型外或埋入表面：在 Blender 对真实网格射线取样，校正肩部、背部地形高度。
5. 窄屏角色被聊天窗覆盖：三维画布复用现有 `--hud-height` 留出底部空间，ResizeObserver 跟随原版 HUD；未另建界面规范。

## 尚未完成

当前骨骼模型仍是可动制作基线，整体美术尚未达到用户要求的高级 2D 统一观感；全貌尺度层次、局部构图、普通石头人、自然环境密度、水云效果和生态内容继续制作。全身与所有内部区域没有一次建完。

软件渲染环境为 Chromium 1228 / SwiftShader，肩部省电模式样本 p50 219.1 ms、p95 290.2 ms（28 draw calls、173142 triangles），明显不满足流畅目标；不能当作实体 GPU 性能验收。运行样本无页面异常／控制台错误。实体低端 GPU、长时运行及延迟网络下手感待验，未授权的玩家预测仍未加入。水面视觉波形与服务端水平水位／救援判断分开，GPU 波浪不充当权威碰撞。

Astra 完成核心；Luna / max 仅承担素材／授权整理、既有地图测试和双客户端检查脚本适配。
