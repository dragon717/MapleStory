# 巨石之约：港口与移动巨像首个可玩候选

2026-09-20。用户语音任务 `01a0ba91-0d07-7e02-acce-6e3b11e5b98b` 明确授权实现并要求实际浏览器检查，覆盖旧技术调研阶段的只读限制。Astra 亲自完成权威规则、协议、持久化、Three.js 场景与接入；Luna / max 只制作独立人物／封面素材，并补齐已有风铃素材台账。没有提交、推送或切换线上 3010，没有改用户数据库或陪测机器人。

## 可运行范围

- 现有活动列表第三项正式命名《巨石之约》，复用账号、角色、装备、登录和 WebSocket。进入暂停旧 Phaser 场景的逻辑、绘制和声音，退出恢复来处。首个候选为 `20260919195219-184bd9ea`，协议 **31**；原版内容保持 `tms273-33`，新增活动内容 `colossus-runtime-0.1`。
- 登岸后以蓝旗高台与向前移动的人群给出动机；普通小石头人快速跑、大石头人慢随并伴随轻震动。普通大石头人约 4–5 玩家高，与远古巨像使用独立造型和运行对象。
- 第一处缺口能跳过，也能落到安全下层继续。桥头靠近后普通攻击割藤，服务器先持久化再放桥；桥落稳后成为可碰撞道路，等待的 NPC 通过，其他玩家同时看到公共变化。
- 高台自动拉高镜头；海中的礁石从始至终就是同一组手掌／手指几何，随巨像抬升，指缘有局部立体水幕。迟到玩家可回看当前远景；跳过只改变本人位置和镜头，不替别人开桥、不改公共世界时钟。
- 巨像停稳后，从高台末端登上手掌，继续沿其局部肩部弧形坡道跑跳，进入村落外部并走到神庙外廊。巨像是实际承载乘员的移动参考系；站立时随其位移和转向，跳离和落地有速度传递。
- 可回看操作帮助、切换三个镜头角度、省电画质、声音和返回来处。帮助打开时阻断移动；失足落到服务器海面以下的安全阈值会回到浅坡，不反复扣血致死。

这只覆盖第一幕港口及相邻揭晓所需闭环。肩部村落／神庙目前是可达外部空间，不等同于内部探索、全部十二幕或完整世界生态完成。肩部道路与外廊是本轮实现衔接，不把它写为用户已确认的后续剧情。

## 制作与验证边界

- **不是终版美术**：目前为有配色、轮廓和实际光照的低多边形场景；港口 NPC 为生成透明单帧面片加运行位移，缺完整动作帧。建筑／巨像表面、海浪密度、水幕形态仍需按漫画方向细化。封面是概念插画，不冒充实机截图。
- 本机验画面使用 **Chromium SwiftShader 软件 GPU**。它能暴露绘制成本、遮挡和像素问题，不能证明实际低端 GPU 达标；实体 GPU、长时热稳定、真实音响听感、不同网络延迟与丢包尚未验。省电档提供可操作退路，不许据此承诺帧率。
- 默认无客户端预测；输入经服务器 20 Hz 权威处理后显示，真实网络延迟会直接影响手感。未获得预测授权，不暗加客户端碰撞或结算。
- 平面角色在不同视角保持可见，正常柱体／巨像遮挡仍存在；当前三个离散镜头角度不等于支持任意自由相机。水面泡沫从世界坐标求值，不随屏幕角度重新贴图。
