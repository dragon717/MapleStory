# 活动场景物理与重制资料索引

本页是元素/物理规则与制作资料的导航，不另维护任务状态；当前范围见[计划](../plan/PLAN.md)。2026-10-01用户要求先整理，巨石之约以后重做，本轮不改碰撞、玩法或模型。用户口述“枫林岛”，现有地图/活动名为“风铃岛”，名称关系待核对，不擅自改名。

## 风铃岛与风铃桥：元素、碰撞和物理响应

当前活动采用Phaser呈现及Rust权威移动/有限状态机，不是通用刚体/流体物理引擎。下表是源码中已有规则入口，不代表本轮重新实玩通过。

| 元素/场景 | 现有响应与权威边界 | 实现入口 |
| --- | --- | --- |
| 根道、坡面、落脚与跳跃 | 地图foothold/连接关系决定可站立与移动；扫掠落地不能由图片轮廓代替 | [共享地图](../../shared/windbell.json)、[通用移动](../../server/src/movement.rs)、[几何](../../server/src/geometry.rs) |
| 绳索与落树桥 | 交互范围/状态校验后进入下落状态；真正落定时增添动态foothold并连接两端，失败/重建走相同几何恢复链 | [活动规则](../../server/src/windbell.rs)的树桥状态与`restore_windbell_tree_bridge_geometry` |
| 干枝、湿木与热作用 | 使用明确材料及状态转换，干湿材料不任意互换；热作用是有限规则，不是所有物体均可燃烧 | [活动规则](../../server/src/windbell.rs)、[材料与生活推进](../../server/src/windbell_life.rs)、[分支图册](../design/windbell/BRANCH_ATLAS.md) |
| 热流、叶翼与滑翔 | 指定热区、燃烧时窗及已展开叶翼共同决定上升；离开热区后受滑翔期限/落速约束，继续走共享落地碰撞 | [活动规则](../../server/src/windbell.rs)的`prepare_windbell_player`及`step_windbell_player`、[通用移动](../../server/src/movement.rs) |
| 公共桥面施工 | 安装的桥段才进入权威可走几何；视觉施工进度与有效桥面对应，现场材料有限 | [共享参数](../../shared/windbell.json)、[活动规则](../../server/src/windbell.rs) |
| 货车、NPC与到货 | 扶车、搬料、运输及NPC推进为服务器事实/状态机，不据此声称有自由推挤刚体 | [活动规则](../../server/src/windbell.rs)、[生活推进](../../server/src/windbell_life.rs) |
| 岛实例、退出和持久化 | 个人岛实例与公共桥分开；退出/断线恢复与稳定进度按既有事务处理 | [活动规则](../../server/src/windbell.rs)、[存储检查](../../server/src/windbell_store_acceptance.rs) |
| 水与其他元素 | 通用移动已有水域支持，但风铃共享地图当前water数组为空，不冒称岛上已完成水流碰撞 | [共享地图](../../shared/windbell.json)、[通用移动](../../server/src/movement.rs) |

呈现入口：[地图安装](../../client/src/features/windbell/maps.ts)、[场景](../../client/src/features/windbell/scene.ts)、[活动UI](../../client/src/features/windbell/activities.ts)。前端动画负责表达权威事实，不独立决定材料消耗、桥面连接或到达路径。

已有定向检查入口：[服务端规则](../../server/src/windbell_acceptance.rs)、[存储](../../server/src/windbell_store_acceptance.rs)、[显示数据](../../client/src/features/windbell/runtime.check.mjs)。后续实际改动才运行受影响检查，不启动独立QA。
