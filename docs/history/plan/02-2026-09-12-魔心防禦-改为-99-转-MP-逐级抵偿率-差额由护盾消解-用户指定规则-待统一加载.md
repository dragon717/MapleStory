# 魔心防禦（2001002）改为「99% 转 MP × 逐级抵偿率，差额由护盾消解」：用户指定规则，待统一加载实玩（2026-09-12）

> 归档位置：`docs/history/plan/02-2026-09-12-魔心防禦-改为-99-转-MP-逐级抵偿率-差额由护盾消解-用户指定规则-待统一加载.md`　　归档顺序：02/66（PLAN.md 原倒序）


- 用户口径（2026-09-12，三条锚点 + 两次澄清 + **一次修正**）：受伤的 **99%** 改由护罩接下、转由 MP 承担，
  逐级「MP 抵偿率」为 1 级 100%、每级 −2、**10 级正好 80**（100/98/96/94/92/90/88/86/84/80）；
  一切**向下取整**；技能窗文案按世界观语言重写。
- **修正（2026-09-12，用户驳回首版「伤害守恒」理解）**：抵偿率化不去的差额**不是回落 HP**，而是
  **由护盾消解**（既不扣 HP、也不扣 MP）；**HP 恒为未被接下的那 1%**。用户原话：
  「100 点伤害，一级时 99 点 MP 扣掉、1 点 HP 扣掉；十级时 99×0.8 点 MP、1 点 HP 扣掉。」
  首版把 `HP = 伤害 − MP` 写成守恒（10 级会漏 3 点血）已废弃；现为三步：
  `接下 = floor(伤害×99%)` → `MP = floor(接下×抵偿率%)` → `HP = floor(伤害×1%)`，护盾吃 `接下 − MP`。
  （MP 不足时仍按技能窗承诺把欠缺部分漏到 HP；这是本作对源语义的保留，不是守恒。）
- **与原版的冲突已核并记录**：本地 `Skill/200.json#2001002` 的 common 为 `x="15+7*x"`（22→85，
  含义是「以 MP 代替的伤害百分比」，老实现是 `ceil(伤害×x%)`）、`mpCon="8+u(x/2)"`、
  `info/switchDamtoMP=1`；源里**没有**「99%」「抵偿率」「护盾」这三个量（真实 MS 的一转魔心防御也不是
  这个形状）。故本条按**用户指定**落地、不冒充原作；`x` / `rawCommon` / `sourceMetadata` 继续写源记录。
- 数据（**单点**）：`scripts/tms273_skill_manifest.cjs` 的 `USER_SPECIFIED_SKILL_RULES['2001002']`
  = `{ fields: { mpSubstitutePercent: [...] }, effect, description }`。同一张表驱动两处投影：
  `mageRules()` 的逐级字段（→ `shared/mage-skills.json`）与 `skillManifest()` 的
  `levelDescriptions`/`description`（→ 客户端技能窗）。`runtimeCommon()` 现在支持**逐级数组**
  （长度必须 = maxLevel，投影时按级取值），新字段名故意与源字段区分开，**不把用户数值伪装成源公式**。
- 服务端：`mage.rs::MageLevel` 新增用户指定字段 `mp_substitute_percent`（0..=100 校验 +
  2001002 必填，原 `x` 仍保留）；`world.rs::commit_incoming_damage` 的 guard 分支改为
  `接下 = floor(减伤后伤害 × MAGIC_GUARD_COVERED_PERCENT(99) / 100)`、
  `MP = floor(接下 × 抵偿率 / 100)`、`护盾 = 接下 − MP`（不入账）、
  `HP = floor(减伤后伤害 × (100−99) / 100) + MP 欠缺`（全走 i128 防溢出）；
  **整段门控在 `snapshot.3`（技能启用）之内**，未启用时显式回 `(0, 减伤后伤害)`。
  **零新协议、零客户端源码改动。**
