**源链在本地不可达（已核实的三条硬事实）**

1. 目标地图 `240010501`（葛雷托所在的祭司之林）**不在源包**：`WZ_JSON_TW/Map/Map/Map2` 里没有任何
   `24001*` 地图；装配内容 198 张图里也没有。
2. 执行脚本缺失：`q36330s/e`、`q36331s/e`、`q36332s`、`q36333s/e`、`q1453s/e` 都不在源包，
   即「对话到什么程度、在哪一步把 `211` 改成 `212`」无法从源复原。
3. 因此源链**只能作为设计依据**，不能作为可执行入口。

**两条可执行路线（都记 P，落到 `shared/job-advance.json`）**

- **路线 A（推荐，与二／三转同构）**：`Lv100` + 前置任务 `job-211` / `job-231` 完成，
  在**漢斯 `1032001` @ `101000003`** 接取一次试炼（击杀 + 收集，见 §5.2），交付即转职。
  优点：与既有六条同一位转职官、同一套分发与事务路径，客户端零新增界面。
- **路线 B（冰雷同构的 Lv100 入口）**：`Lv100` 对话直接转职、不发试炼。这是冰雷线四转
  当前的形态（`spEvidence.runtimeDecision` 记的初始 3 SP + 历史 MSEA 分档，属 P），
  优点是与已跑通的线完全一致；缺点是「转职任务目标和完成要求」是空的。

建议：**A 为默认、B 保留为快捷入口**（源链本身也是「剧情 + 一次转职」，A 更接近源结构）。

（会自指，也会指向其它职业的变体号如 `214xxxx`），两者在源里是两个字段，不能混读。
