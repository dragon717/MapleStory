# 余途：回风原的世界基础与二次生长

2026-09-20。依据自主开发委托 v2.0；实施状态与待验项只在 [PLAN](../../plan/PLAN.md)，本文定义本轮实际契约，不作为另一份进度表。

作品工作名 **余途**，世界名 **回风原**。承诺：**每次远行留下来路，每次归来遇见变化。** 名字尚未进行商标或商业使用核验。

## 范围与地方

本轮将风铃岛的能力学习、渡口的公共通行、补给、桥下旧路记、普通战斗和既有死亡痕迹接成同一段可反复生活的地区。保留原版复刻区，角色继续使用已有职业、技能、背包、掉落、经验和复活规则，不另造原创版资产系统。

作者设定：渡口西岸是林圃，东岸是歇脚棚，石脊通向风铃岛；桥影中的石台避风，适合整理水浸的旧纸。林圃产出的是含食物和燃料的补给包，居民与旅人共用。它们分别对应实际仓位、车程、恢复、烘纸和入口，不展示未做的远景区域。

运行事实：桥段和下层河道都是真实 foothold；桥恢复后保留，货车往返不靠重毁桥制造任务。桥下蜗牛使用导出的 `100100` 模板、普通命中/受击/经验/掉落/重生。蜗牛靠近石台时，槐生停止加热；可以等待、引开、战斗或绕行。战争、天气系统与完整生态不在本轮承诺中。

个人岛继续沿用原有实例语义：每次练习重建绳桥和一份干枝，临时燃料不能带进公共库存；角色学习、到达和岚织的相遇记忆长期保存。公共渡口只有一个桥状态、一辆车和一份旧路记，未贡献者也能使用。这里没有把个人岛伪称为多人共享地形。

## 六个闭环与唯一所有者

| 闭环 | 本轮行动、反馈和真实后果 | 保存、稳定与恢复 |
| --- | --- | --- |
| 理解与探索 | 观察根道/树桥/热流 → 亲自到达 → 岚织教授折叶 → 渡口滑降或重访旧岛；东岸石脊有可用的岛入口 | `World` 的玩家移动与岛实例负责碰撞；个人到达与学习持久化；热流失败仍可走根道 |
| 能力与实践 | 叶翼只限制下降速度并提高有限滑翔速度，热流按区域施加升力；不传送到目标。蜗牛使用普通战斗，清场成为火盆的安全输入 | 同一个移动状态与原战斗结算；一次起落不可重置滑翔时限；落地可再练习；换图清临时飞行 |
| 资源与供给 | 修桥材料消耗 → 首车到达 → 林圃生长 → 同车装载/运输/卸货/返程 → 居民使用、旅人休息、烘纸 | `WindbellBridgeState.life` 唯一拥有库存；初始 12 份，之后 `现存 + 已耗 = 12 + 已产`；短缺等待运输恢复，无刷新领取 |
| 地方与居民 | 原有 6 木板/3 绳修通三段 → 运抵后持续供给 → 阿苇往返、槐生等安全条件烘纸 → 公开旧路记稳定可读 | 桥不重毁；首运状态不重置；纸干是稳定成果。没有玩家时生活仍推进，危险在旁则合理等待 |
| 关系与身份 | 到达后交谈获得真能力；槐生亲眼见过烘纸才记住帮助；晚到者可读同一成果；“我的来路”保留本人的实际经历 | 角色 JSON 保存各位知情者独立的有限记忆；所有读写由权威行动提交。没有后台给 NPC 共享全知经历 |
| 失败与再出发 | 热流错过落点留下失败提醒；河道战斗可受伤/死亡 → 原惩罚与公共墓碑 → 复活 → 棚中有限补给恢复 → 继续出发 | 复用正式死亡和恢复事务；不发死亡奖励。墓碑沿用 30 分钟、同图最多 8 的现有政策，复活不抹去墓碑 |

玩家不必帮助：桥沿旧节奏自救；供给按日常工作继续；槐生在安全且有补给时自己处理纸页。事后仍能休息、练习能力、战斗、读旧路记或离开。这里不承诺自动生成新故事，也没有签到和错过惩罚。

## 提交与运行预算

- `windbell.rs` 接受认证行动，校验实例、死活、距离、能力、库存和现场危险。先计算临时变化，再通过 `Store::commit_windbell_action` 将公共状态、局部记忆、恢复 HP/MP、行动序号和回执一起提交；失败恢复旧内存，不发恢复跳字。
- 每角色持久行动序号只增。旧序号即使已从回执窗口移除也拒绝；最近 64 个回执支持精确重放，运行时请求缓存全世界最多 256 项。旧 JSON 默认序号 0；旧协议客户端由版本门禁阻止进入。没有清空存档换兼容。
- 生活每 5 秒结算一步；林圃每 20 秒最多补一份，居民每 30 秒消耗一份。两岸各最多 12、车上最多 4。装货 10 秒、单程 15 秒、卸货后休息 20 秒；无需求时留在装货处。
- 单次离线补算最多一小时／720 步，之后视为居民休息，库存和在途货物保留；时钟倒退不重复生产。离线环境采用恢复时的安全状态，不伪造断线期间逐秒怪物轨迹。车的位置从已提交车程投影，不每帧写库。
- 角色只留固定数量的经历字段，纸页只有三层湿度及一份燃料；不保存无限逐帧历史。桥 JSON 默认兼容没有 `life` 的旧首运记录，到货后才初始化日常供给。
- 槐生烘纸需要一份公共补给；正常行动在纸干时停止，不允许按钮把历史烧毁。纯材料规则仍明确：继续给干纸加热会燃烧。这是火盆操作边界，不是另一种纸的物理。

## 本轮实际二次生长

第一组基础是现有岛的环境路线，加上本轮贯通的持续供给与持久叶翼。第二组是**湿纸 + 槐生 + 桥下石台情境**：新材料使用同一个热作用，新人物读取同一公共库存和附近真实怪物，新情境使用已有下层地形、翼的移动语义、普通战斗与掉落。旧岛的根道、树桥和热流继续成立。

主要接入文件是 `windbell_life.rs`（有限生活及材料规则）、`windbell.rs`（行动、人物及地图接入）、`shared/windbell.json`（NPC/石台/刷怪点）、既有活动与场景视图。新增序号只补现有事务边界；没有另建任务、规则解释器、存档库或行为树。

## 表达、来源与边界

当前运行沿用分层 **2D Phaser**，不是旧文档里的 Three.js/Blender 运行方案。地面、绳桥、火动画、蜗牛和玩家素材继续使用已有 TMS273 导出；原风铃人物、树和道具来自项目现有创作资源；槐生是本轮 AI 生成的原创候选。改名不改变这些来源，也不代表商业素材授权已核验。

声音复用现有风铃、到达、材料、翼展开等实际 OGG；还原快照不重播一次性声效。公共库存、旧纸干湿、人物位置和对白来自同一快照。阿苇实际随车位移时交替使用两张原创行走帧，停下回到站姿，朝向跟随服务端移动；其他人物保留站姿。槐生和阿苇新帧的生成 PNG 原样复制，缩放及脚点由图集元数据表达。没有手部搬运、递纸和烘纸的专用动作；烘纸以纸面、文字和声音变化表达。具体观感由用户实玩核定。

后续内容边界：更深天命权柄、经验球与觉醒人格、跨地区贸易、天气和多区域生态尚未实现。本轮不搭空框架。真实视觉、脚点、手感与情绪体验由木鸟按仓库政策亲测，工程通过不能代替“值得回来”的判断。
