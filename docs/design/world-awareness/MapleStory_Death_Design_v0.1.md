## 0. 核心命题

**玩家失败了，但他的失败没有被世界抹掉。**

死亡首先结束玩家这一段行动，而不是开启一条更高效的收益路线。角色可以复活，已经发生的死亡却成为世界事实：墓碑留下名字和简短的墓志铭；罕见的魔念虚影接住一段未完成的渴望；后来者可能受到它的帮助，也可能因它不再属于生者而遇到危险。更少数虚影在相遇、冲突与融合中逐渐形成自己的选择，成为不再属于原玩家的独立人物。

我们不把这一机制叫作“死亡奖励系统”。它是**死亡事实进入世界规则后，继续产生后果的过程**。

本设计既保留“失败留下痕迹”的温度，也保留死亡的分量：不是人人必出虚影，不是待得越久必然封神，不是自杀次数换取天命资格，更不是把死亡角色变成离线刷怪宠物。

### 0.1 先固定六条设计决策

| 决策 | 本版约定 |
|---|---|
| 幽魂和虚影不是同一个东西 | 幽魂是死亡表现，虚影是独立世界实体；复活只结束前者，不删除后者 |
| 来源不是所有权 | 虚影来自某次死亡，但不属于该角色；原玩家不能指挥、回收或继承其收益 |
| 善意和危险分开表达 | 行为意图可以保护，接触属性仍可能伤害生者；危险必须可识别、可躲避 |
| 经验不能凭空增加 | 经验球来自真实怪物的一次结算，不来自墓碑、虚影寿命、融合或觉醒 |
| 觉醒必须形成新人物 | 保留片段经历，不复制账号、装备、任务进度或原玩家天命 |
| 先做可玩的因果，再接宏大体系 | 墓碑 → 虚影护路与风险 → 后来者拾取，是完整首个玩法闭环；融合、NPC、天命逐级开放 |

### 0.2 保留什么，不擅自改什么

现有死亡、复活、职业、药水、经验与主线规则的变化必须单独列出；不能借“死亡设计”顺手重写。本次核查可确认：受伤入口在持久化候选状态成功后才更新玩家；复活按当前死亡标识去重，并将 HP 恢复至 `min(50, max_hp)`，MP 保持原值。[R05][R06]

完整愿景覆盖正常世界里的死亡；首发仅在白名单范围灰度，未开启范围保留现状。这是发布范围限制，不是已经宣称全世界每次死亡都接入完成。

本方案不自动增加经验扣除、不掉落玩家装备、不清除背包、不降低永久属性，也不默认添加新的免费药水。此前讨论的“有限药水供给与死亡帮扶额度”保留为独立经济设计：若将来接入，必须共享同一次死亡的幂等凭证，而不是每次读墓碑、重连或生成虚影再发一份。

## 1. 冒险岛语境：熟悉的外壳，原创的因果

### 1.1 表现方向

保留用户指定的“墓碑落下、角色短暂幽魂、复活离开”体验方向。正式图像优先核查项目本地 `参考/273` 中可用的同版素材与导出结果，记录源路径、origin、锚点和帧时长；本次未访问这些未入库资源，**不能声称已经找到可直接使用的墓碑、幽魂或经验球贴图**。[R02]

新增虚影、阴阳干涉、融合和觉醒是原创 P 内容。美术可以延续冒险岛清晰轮廓、角色脚点、层级遮挡与轻盈的魔法表现，不把一切改成重度恐怖。稀有虚影可以有熟悉的职业动作轮廓，但不能把原玩家的全套装备与技能完整复制进世界。

“魔念”在本设计中指**留在世界里的强烈未竟倾向**，不是“这个人生前邪恶”的道德判定。面向玩家可使用“残响”“守路虚影”“未归之影”等具体称呼，避免每一位助人虚影都被 UI 叫作敌人。

### 1.2 不用原作名词冒充授权规则

不把原创阴阳规则强行归因于某个原作阵营或角色，也不宣称原版 NPC 本来具有“吸收玩家灵魂”的能力。区域故事、虚影新名字及后续天命冲突以原创支线叙事承载，不覆盖冒险家原有任务。

《Minecraft》仅作为用户指定的“短暂漂浮、由活人拾取的经验球”交互比喻；不照搬其数值、掉落归属、附魔或死亡经验公式。

## 2. 六种对象，六种不同的生命周期

| 对象 | 是什么 | 有无自主行为 | 终止条件 | 与玩家的关系 |
|---|---|---|---|---|
| 死亡记录 | 某个角色在某个范围、时刻、原因下死亡的事实 | 无 | 按历史保留政策压缩；关键来源不可提前删除 | 记录来源，不是装备或奖励 |
| 短暂幽魂 | 刚死亡角色的非交互表现 | 无 | 复活或表现时长结束，以先到者为准 | 属于角色当前死亡表现 |
| 墓碑 | 死亡地点的临时纪念痕迹与墓志铭入口 | 无 | 到期转为历史摘要 | 可纪念，不可拾取、交易或当作障碍 |
| 魔念虚影 | 某次死亡留下的独立残响 | 有限目标与行为 | 消散、被消解、吞噬、融合或觉醒 | 来源关联，不接受原玩家命令 |
| 经验球 | 怪物结算后暂存在世界里的经验 | 无 | 成功拾取或到期耗散 | 未领取前不属于任何玩家 |
| 觉醒 NPC | 经演化形成的独立历史主体 | 持续目标、记忆与有限计划 | 长期存在，但仍可迁移、退场或遭遇终局 | 有来源，不是原玩家的另一个账号 |

同一个玩家可以站在自己的墓碑旁，也可以遇见源自自己的虚影。玩家与虚影同时存在不构成两个“同一个人”：前者继续自己的人生，后者拥有来源于这次死亡、但逐渐偏离的生命史。

### 2.1 总体因果

```text
服务端确认死亡
  ├─ 角色：死亡状态 → 短暂幽魂 → 复活继续冒险
  ├─ 世界：死亡记录 → 墓碑与墓志铭 → 到期成为历史
  └─ 条件成立且稀有判定通过：潜伏残响 → 魔念虚影
       ├─ 对怪物行动 → 一次怪物结算 → 短暂经验球 → 后来的活人
       ├─ 与生者接触 → 可预警的阴阳干涉 → 躲避、安抚或安全退让
       ├─ 与其它虚影相遇 → 冲突／吞噬／融合 → 新状态与来源记录
       └─ 极少数形成独立选择 → 觉醒 NPC → 候选与承担 → 天命竞争
```

树上的分支不是全员必走的升级路线。绝大部分死亡只留下墓碑；绝大部分虚影最终消散；觉醒不等于获得天命。

## 3. 一次死亡，玩家具体经历什么

### 3.1 刚刚死亡

致命结果由服务端确认。停止玩家攻击与输入效果，保留当前失败信息。墓碑从上方落向经过校验的展示落点；短暂幽魂出现。幽魂不碰撞、不可攻击、不能拾取、不能探索新区域，也不能以死亡视角持续获取额外侦察优势。

死亡不是另一种操控模式：不提供幽魂移动、不提供灵魂技能栏、不允许死者指挥虚影。复活入口保持清楚，不要求玩家观看完整演出。

若死亡发生在悬崖、水中、绳索或传送边界，历史保存真实死亡坐标；墓碑可吸附到同一范围内安全、可见的合法脚点。**展示位置的修正不能改写死亡事实，也不能把危险实体挪到复活点或主线入口。**

### 3.2 复活之后

角色按现有复活流程离开死亡状态。幽魂立即结束；墓碑继续存在；潜伏残响若已经判定形成，不因玩家离线、换图或复活而取消，也不因多按几次复活而增殖。

普通读墓碑只是一段简短互动，不改变任何资源。玩家可以看到“这里曾有人倒下”，而不一定知道他的全部经历。

### 3.3 墓志铭

首版使用服务端白名单模板与已知事实组合，不开放自由文本输入。

| 事实依据 | 可以出现的文字 | 不应该出现的文字 |
|---|---|---|
| 玩家在护送区域中成功拦截过攻击 | “他最后仍守在旧路旁。” | “他是服务器最无私的人。” |
| 玩家曾完成明确的返程行动，但死于途中 | “这一程，他未能走到终点。” | 虚构家庭、遗书或现实经历 |
| 缺少明确事件证据 | “一位冒险者曾在此倒下。” | 根据低血量自动判定悲壮牺牲 |

名字显示采用角色已公开的显示名快照；允许匿名显示。改名不改写旧死亡事实，但隐私删除或敏感名称处理需要受控脱敏。碑文不带账号标识、私聊、好友名单或完整死亡流水。

在同一点连续发生大量死亡时，可将墓碑视觉聚合为一处“此地的纪念”，展开后分页查看；每次有效死亡仍有独立记录，不能为了少画几个对象而把死亡事实合并成同一个 `death_id`。

## 4. 虚影如何形成：有条件的罕见后果

### 4.1 不是“死亡一次，抽一次大奖”

形成虚影需要依次满足：允许承载死亡残响的地图范围、真实有效的经历、生成预算、重复死亡限制，最后才是一次稀有判定。安全城镇、登录区域、复活保护区、Boss 练习副本、GM 调试与明确排除的剧情失败不生成有收益能力的虚影。

生成资格来自**死亡之前已经成立的经历**。停在低血量状态、重复挨同一只怪物的伤害、挂机、重复自杀都不自动等于“千辛万难”。即便发生了值得记录的经历，也不保证生成。

可参考最近 120 秒内的有界事实摘要，并关联仍有效的护送、救援或区域危机事实；这是初始工程窗口，不代表人的真实意志只有两分钟。

### 4.2 把渴望理解为可解释的行为倾向

| 倾向 | 可用证据示例 | 虚影优先尝试 | 可能产生的矛盾 |
|---|---|---|---|
| 守护 | 为经过者拦截真实威胁；守住具体地点 | 守在路口，攻击威胁附近生者的怪物 | 它靠近保护对象，却使对方受到阴阳干涉 |
| 讨还 | 在同一明确事件中持续对抗某类威胁 | 追逐该事件中的威胁 | 执念使它偏离原本需要保护的道路 |
| 归途 | 有真实目的地与返程进展 | 试着回到一个地点 | 新修好的路与记忆中的旧路不一致 |
| 寻觅 | 参与过真实寻找、探索或救援事件 | 在相关地点停留、巡视 | 后来者帮助它理解“寻找已经结束” |

首版只实现“守路”一种可核验行为。证据不足的虚影采用中性的“徘徊”，不要由大模型凭空补一个人格判决。证据、倾向、行为选择三者分开保存：改变倾向不等于改写历史。

### 4.3 强度不是复制角色战力

初始表现可以引用死亡时的有限外观片段；战斗能力由区域等级、行为原型、有限残响强度决定。高等级玩家不能故意死在低级区，留下横扫整个区域的永久分身。

虚影有三个不同维度：**凝聚度**决定能否维持存在，**偏向**影响目标选择，**失衡度**影响与生者接触的风险。三者不是一条通用经验条。杀怪不会让虚影获得玩家经验；融合可以改变结构与凝聚度，但不能无限扩张战力和寿命。

## 5. 善意与风险同时成立

### 5.1 意图友善，不等于接触安全

虚影看到怪物靠近旅人，会尝试拦截。它没有主动伤害旅人的目标，但自身携带的死亡侧扰动可能伤及近处生者。危险来自明确的空间和状态条件，而不是随机给玩家一个无法解释的扣血。

第一版采取“可观察、可退让”的规则：进入干涉距离后先显示轮廓、地面边界与轻提示，再结算周期性的风险；离开距离后停止积累。视觉提示不能只依赖颜色，音效也不能成为唯一预警。

不能让虚影瞬移贴脸、隔墙穿层伤害、出生在复活点、在不可跳过的 NPC 窗口后方默默造成致命伤害。会伤人的虚影必须与生者共享可理解的空间约束。

### 5.2 首版和后续危险的边界

P2 首次开放的阴阳干涉为**非致命接触伤害**：可造成紧张、需要躲避，但这一来源自身不能把 HP 从正数降到零。伤害仍走既有防御、护盾和魔心防御口径，只在最终生命扣减处额外限制致死；不能先扣完血再给玩家补回来。

这并不把用户设想永久改成“不会致死的善良幽灵”。后续高失衡区域可以开放明确预告的致命干涉，但必须独立开关、清楚的避难路径和专门验收。环境同时存在其它怪物时，非致命干涉仍可能制造危险，不能在界面宣称“处于虚影旁绝对安全”。

虚影导致的后续死亡可以留下普通墓碑，但首版**不再生成可战斗虚影**，防止“一个虚影制造一串死亡，再制造更多虚影”的正反馈灾难。

### 5.3 生者怎样应对

首版的最低对策是看见、绕行、退回安全距离和使用现有生存手段，不依赖新生活技能。后续再加入有限的安抚、引导、镇定或护持，必须有真实输入与效果，不新增强制日常。

暂不开放玩家随意击杀他人的虚影、拖着虚影穿过城镇或把墓碑当作建造材料。需要治理的失控实体可由受控 GM 命令消解，必须记下原因，不返还或重抽稀有机会。

## 6. 虚影击杀与经验球：让后来者受益，而不是让死者回本

### 6.1 经验从哪里来

怪物真实死亡时，服务端只结算一次。纯虚影击杀不向虚影、原玩家、原玩家队伍或离线账号发经验；将其中一部分可结算经验转为短暂停留的经验球，其余耗散。

经验球不是背包物品，不占格子，不能存仓、邮件转移、拍卖或交易；活人拾取后直接进入既有经验与升级流程。虚影死亡、墓碑到期、融合和 NPC 觉醒本身都不产生经验球。[R08][R11]

### 6.2 谁可以拾取

同一真实地图实例中的活人，经服务端距离、期限、资格校验后可以拾取。原始死亡所属账号及其角色不能领取由该来源虚影生成的经验球；融合后的虚影继承全部来源账号的排除关系，不能通过融合“洗白”来源。

领取排除关系以经验球生成时的根来源快照为准。球已经生成之后，虚影再吞噬或融合，不会追溯改变这个旧球的来源；演化后新生成的球才使用新的完整来源。

不扩大为“朋友也不能拿、队友也不能拿”：那会破坏帮助后来者的意义。账号排除只能减少最直接的自收益，不能证明已经杜绝小号或串通；仍需生成节流、有限杀怪预算与监测。

宠物自动拾取、远程吸取和离线自动领取首版关闭。经验球是公开而有限的机会，不做每位路过者各领一次，也不做原玩家回来优先领取。

### 6.3 混合战斗必须先定义，再写代码

玩家与虚影可能同时伤害一只怪物。不能在原来的完整经验奖励之外，再凭虚影的最后一击额外生成一份经验。

本版针对**启用了虚影结算的试点遭遇**采用以下 P 规则；完全没有虚影参与的旧战斗保持原口径：

- 只记录真正扣掉怪物 HP 的伤害；过量伤害不算贡献。
- 以这只怪物一次死亡的基础经验预算，按有效生者伤害、有效虚影伤害分区。
- 生者份额按服务端认可的实际角色分配；虚影份额最多转化 25% 为球，其余耗散。
- 队伍额外经验只可依据生者份额计算，不把虚影当队员，不对经验球再次加成。
- 纯虚影击杀不生成枫币、装备、任务道具、Boss 结算、图鉴掉落卡或任何所有者奖励。
- 混合战斗中，只有生者有效贡献达到基础 HP 的 50%，才开放原有普通物品掉落候选；归属按真实生者贡献决定。任务击杀仍遵守已存在的实际落地者规则，不记给虚影的来源玩家。

**例子：**基础经验 100，生者实际打掉 40 HP、虚影打掉 60 HP，怪物基础 HP 为 100。生者基础份额 40；虚影份额 60 中产生 15 经验球；剩余 45 耗散。不是生者先拿 100，再掉 15。该例未达到普通物品掉落的生者贡献阈值。

这条混合规则有真实取舍：虚影介入可能降低玩家获取完整狩猎收益的效率。首版 AI 因此避免抢已经由玩家占据的普通战斗，玩家开始有效进攻后停止追加非必要攻击；试点不覆盖任务关键怪、Boss、可治疗／多阶段怪物与活动奖励怪。后续若改变阈值，必须单独复核玩家是否感到“被帮倒忙”。

### 6.4 失效和失败

经验球到期便耗散，不进邮件、不返还原玩家、不补发到下一张图。两人同时拾取，只允许一个成功；数据库失败时球不能假消失，也不能先播升级再回滚。重连根据当前服务端状态恢复，不能依赖浏览器缓存重新造球。

## 7. 吞噬与融合：留下新事物，不制造永动机

### 7.1 两种不同过程

**吞噬**是冲突后的吸收：一方失去独立存在，另一方保留主要偏向并获得部分残响，同时承担失衡或记忆冲突。

**融合**是形成新主体：两个旧虚影结束，产生一个新虚影。新虚影保留可追溯来源，但不简单等同于其中任何一个。

为避免“表上写融合，表现只是加一级”，首个融合内容至少应让目标选择、外观轮廓或对某段道路的反应发生一个可观察改变。

### 7.2 发生条件

相遇只是必要条件，不是每次接近都自动合并。允许在特定区域，由相容／冲突的偏向、可见的聚合前摇、双方状态和区域预算共同决定。单个虚影同一轮只能参与一次演化，刚刚产生的结果不能在同一 Tick 继续连吞。

涉及任何已被消散、吞噬或觉醒的对象，后续旧事件都失效；不能让两次融合各自复制一半历史后造出两个“唯一继承者”。

### 7.3 守恒与边界

合成后的凝聚资源不大于输入总量，首版保留率 80%；剩余经验预算不大于输入剩余预算之和。来源中已消耗的预算不会被忘记。寿命可延续，但不能超过最早来源死亡之后六小时的未觉醒上限。

最多保留 16 个不同根死亡来源；超限时不发生本次演化，不能截断老来源以获得新的领取资格。记忆可压缩成有限片段，但来源排除与收益预算不能采用会漏人的摘要。

虚影被吞噬不代表墓碑被删除。墓碑纪念的是那次死亡；虚影则已进入另一段演化历史。

## 8. 觉醒：从“重复执念”走向“作出选择”

### 8.1 什么算自主意识的游戏表达

本系统不需要证明哲学意义上的意识，也不依赖大模型生成灵魂。玩家能观察到的区别是：早期虚影机械重复偏向，觉醒人物能够保留历史、理解目标已经改变、在冲突中作出不同于原执念的选择，并在以后继续承担后果。

例如：守路虚影原本只会消灭靠近旧桥的怪物；桥修好后，它发现守旧路反而阻碍新旅人，开始选择护送行人到新路。它不是简单变强，而是承认了世界已经变化。

### 8.2 觉醒条件

长时间存在与足够凝聚度只是必要条件之一。还需要有来源的关键经历、不是同一事件的重复刷取、与不同对象的真实相遇、可成立的新选择，以及区域对重要 NPC 的容量。

首个内容要求至少三个不同已提交事件来源、至少两类相互有张力的经历、一次明确的新选择。具体事件可以手写，触发与结果必须读真实状态。数量是内容脚手架，不对玩家展示进度条，也不承诺“做三次必觉醒”。

无人地图里的墙钟流逝不增加经历；停服、挂机、重启和融合次数都不能替代新选择。

### 8.3 继承什么，舍弃什么

| 保留 | 不继承 |
|---|---|
| 根死亡来源、部分可公开经历、有限外观母题 | 账号、登录身份与原玩家输入权 |
| 与世界形成过的真实关系和新记忆 | 玩家背包、装备实例、仓库、邮件、拍卖资产 |
| 与某地、某人或某事件有关的偏向 | 原玩家的任务完成状态、技能树和完整战力 |
| 一个新名字与可持续的历史身份 | 原玩家已经拥有的天命席位或排他权利 |

“长期存在”不是无限堆积、永不消亡。觉醒 NPC 脱离普通虚影 TTL，进入持久人物生命周期，可以旅行、淡出舞台、被迫退让或结束故事；世界保留重要历史，不要求所有旧 NPC 永久站在同一张图。

## 9. 与天命连接：世界也可能认出一个不再是玩家的人

现有天命专题把“实际行为 → 有来源的记忆 → 世界回应”作为起点，并明确区分角色身份、NPC 历史身份、表现实例与素材模板；它是历史设计方案，不能据此声称全部机制已经落地。[R16]

觉醒 NPC 进入天命时，必须以自己的历史主体身份成为候选；其来源玩家既不自动获得收益，也不拥有禁止它参选的特权。候选、承担、馈赠与边界逐级成立，不因“觉醒稀有”跳过资格规则。

### 9.1 存续与守护的冲突样例

以下为原创故事例，不代表现有地图或已实现任务：

一个由多次护路经历形成的 NPC 认为，必须守住每个仍在旧路上等待的人。另一位玩家为了让整个地区恢复补给，选择把有限的材料投入新路，暂时放弃一段危险旧路。两者都可以提出有根据的主张：一个承诺“不弃眼前之人”，一个承担“让更多人得以延续”。

世界不按“玩家优先”裁决，也不按“NPC 活得更久”裁决；它观察谁真正承担了对应责任、如何履行已公开的边界、哪些事实支持当前资格。这里的争夺来自具体位置的责任冲突，而不是突然弹出一个战力竞价榜。

### 9.2 公平边界

NPC 可以竞争，不等于可以在玩家睡觉时无预警抢走正式席位。正式竞争必须沿同一套对玩家也公开的挑战条件、响应窗口、承担与移交规则；首版 NPC 只申请空缺或尚未正式承诺的位置。撤换已任命主体属于另一个经过验证的阶段。

同一世界、同一排他席位只能有一个正式持有者。退出、失格和移交留下历史，而非简单抹掉。天命核心尚未存在时，最多记下有依据的“候选事实待接入”，不发伪造称号、不临时另写一套席位表当作正式天命。

## 10. 与已有及讨论过的相关系统衔接

| 系统 | 真实的连接方式 | 禁止的捷径 |
|---|---|---|
| 世界事实与规则 | 死亡、接触、怪物结算、融合产生明确新事实；规则读取有限输入 | 每新增一种实体就写与全部其它实体的专用交互矩阵 |

| NPC 记忆 | 目击者或获得合法转述的人形成记忆 | 所有 NPC 读取服务器日志后立刻全知 |
| 冒险笔记／图鉴 | 后续增加“见闻记录”：确实见过或互动过的独特现象 | 新增刷死亡、刷觉醒数量的收藏奖励，冒充原版怪物卡 |
| 背包／仓库／邮件／拍卖 | 不复制资产；经验球是即时世界资源，不是容器中道具 | 死亡生成一份装备快照就当作可交易装备 |
| 聊天／广播 | 普通死亡不全服播报；重要世界人物出现才考虑有依据的地区消息 | 每个墓碑跑马灯、公开私密经历、未接入消息层却声称已广播 |
| 离线／失焦保活 | 角色死亡仍由服务端裁决；虚影与来源角色连接独立 | 浏览器失焦就生成虚影，或来源断线便清除虚影 |

| 物理水、火、温度等 | 只有实际存在的规则变量才参与死亡侧条件 | 用几处预设特效宣称已实现全世界阴阳／温湿度模拟 |

当前源码已经有 `windbell.rs` 的有限状态机与有限自主节奏，主世界仍按既有顺序处理；这不等于已经有通用 NPC 人生与天命裁决器。[R04][R15]

## 11. 多人范围、时间与容量

### 11.1 共享事实必须相同

同一公共地图实例中，墓碑、虚影位置、伤害、球是否被领取都只有一份事实。玩家可以看到不同的纪念文字权限或 NPC 对自己的对白，但不能看到互相矛盾的可交互虚影。

私人副本中的死亡不能生成外部公共世界的强者。跨服共享历史、合服唯一性与全球天命暂不实施；范围绑定必须先做好，但不能为了远景重写分布式架构。[R16][R17]

### 11.2 无人地图不是刷收益后台

墓碑和球的到期采用持久化截止时间；重启不会刷新寿命。无人地图不继续逐帧战斗、不产经验、不刷关键经历、不推进融合和觉醒。虚影在自己的截止时间内可以再次被来访者看见；重新激活先同步状态、给危险预告，再允许作用于新来者。

这保留“痕迹比人留得久”，不许诺服务器在无人时完整模拟所有世界。当前怪物重生流程本来就检查地图是否有玩家，扩展不能悄悄改变全部地图的驻留成本。[R19]

### 11.3 初始试点参数

下表是**唯一的 v0.1 默认建议**，都是 P 参数，未做运行测量或平衡测试。技术文档引用本表，不另造第二套默认值。

| 参数 | 初始值／政策 | 为什么 |
|---|---|---|
| 幽魂表现 | 最多 5 秒，复活立即结束 | 不拖延复活，不成为玩法资源 |
| 墓碑可见寿命 | 死亡后 30 分钟 | 给后来者机会，也不让地图永久拥堵 |
| 经历摘要窗口 | 最近 120 秒，另可引用仍有效的关键事件 | 有界记录，不收集完整人生流水 |
| 特许危险区域生成率 | 合格死亡 1%；更强残响子区最多 3% | 稀有且受区域约束；非允许区为 0 |
| 同来源账号／区域生成抽取间隔 | 30 分钟；同一死亡永远只判定一次 | 不能换角色连续重抽 |
| 普通虚影寿命 | 激活后 20 分钟；激活最早在死亡 5 秒后 | 可被看见，不依赖玩家按复活 |
| 未觉醒演化链最长寿命 | 最早根死亡后 6 小时 | 融合不能无限续杯 |
| 干涉预警 | 至少 1 秒；新入图／复活保护至少 3 秒 | 避免加载结束即受伤 |
| 首版干涉伤害 | 非致命；周期与范围必须按试点几何配置 | 不在未验收的空间里默认开启致命链 |
| 虚影经验转球率 | 虚影基础经验份额的 25%，向下取整 | 让帮助成立，减少挂机替代 |
| 单根虚影终身经验预算 | 试点参考怪物基础经验的 5 倍 | 消耗一次、不可重启或融合重置 |
| 区域经验输出预算 | 每 10 分钟最多参考经验的 20 倍 | 限制密集死亡与协作刷取 |
| 经验球寿命 | 30 秒，自实际生成开始 | 形成偶遇，不建立无限储蓄 |
| 混合战斗普通掉落门槛 | 生者有效伤害占基础 HP 至少 50% | 虚影不能替代正常狩猎全部成本 |
| 融合凝聚资源保留率 | 80%，向下取整 | 不产生无损指数增长 |
| 演化链根死亡上限 | 16 | 精确保留来源与排除关系 |
| 单图交互虚影上限 | 8 | 控制空间压迫与模拟成本 |
| 单图经验球上限 | 64；单次结算最多 4 球 | 不把一场战斗拆成数百网络实体 |
| 单图墓碑展示组上限 | 64；超量做分页聚合 | 限制绘制成本，不删除历史事实 |
| 单图重要觉醒人物常驻上限 | 2；溢出需明确迁移／退场内容 | 不把“极少数”做成NPC堆积 |

**预算耗尽的规则必须可解释：**死亡照常留下纪念；可战斗虚影不再生成，或者已有虚影转入无战斗的停留状态。不能生成一个仍会产经验的无记录替身。球容量不足时只物化容得下的正数球，未物化部分耗散，并计入审计；不能先扣了玩家经验再通知容量不足。

## 12. 双向审视：为什么值得做，什么情况下应该收缩

### 12.1 支持这一设计的最强理由

它让多人世界形成不依赖直接组队的联系：一个人的失败为陌生人留下线索、风险、帮助乃至故事人物。死亡不只是一段数值损失，也能成为地图的历史。虚影的善意与危险并存，使世界规则而不是“阵营颜色”决定互动；觉醒后的分歧让 NPC 不再永远服务于玩家。

### 12.2 反对这一设计的最强理由

它可能使失败成为可优化的生产方式，导致故意自杀与小号协作；会干扰原有狩猎和安全路线；共享危险可能被用于恶意引导；“永久 NPC”会造成数据库、叙事与地图容量膨胀。若为了解释所有这些后果而增加大量隐藏分数，玩家感受到的反而是另一套不透明养成。

### 12.3 本版取舍

保留完整方向，但按真实因果逐段交付。首版不做致命连锁、不开放玩家自由操控、不把虚影接到普通 Boss 经济、不宣称所有地图始终运行。体验验收优先验证：“后来者理解它曾帮助自己，也理解为什么不能无限靠近”，而不是先追求虚影种类数量。

## 13. 首个可玩故事与验收画面

以下“桥外旧路”是内容提案名，不是已验证地图 ID；实际地图、怪物、脚点和素材由计划 D00/D01 从现有装配产物中选择。

一位冒险者在侧路阻挡怪物，最后倒在路口。他复活离开，墓碑留下“这一程，他仍守在路旁”。极少数情况下，过了一会儿，一个守路残响留在那里。

后来者经过，看见它击退怪物；怪物消散处留下少量经验球。后来者走近时，虚影身体边缘出现干涉预警，于是绕开它，捡起没有被任何人预先占有的球。原玩家返回时也能看见虚影，却不能指挥它或领取源自自己的经验球。

这一切不要求自动弹出任务。若后来者读过碑，离开时可能理解：**刚才帮他的，并不是一个为了奖励而刷新的机关，而是另一位冒险者失败后留下的痕迹。**

### 13.1 首版成立的七个观察点

| 观察 | 成功标准 |
|---|---|
| 玩家复活离开 | 墓碑继续存在，无需原玩家在线 |
| 后来者刷新／重连 | 看到同一墓碑和虚影，不多出第二份 |
| 虚影击杀允许的怪物 | 不向来源玩家发经验，世界出现有限经验球 |
| 活人接近虚影 | 提前看见危险，能够退出并停止继续受影响 |
| 两人同时拾取一个球 | 只有一份经验到账，另一人收到明确结果 |
| 原玩家回来 | 可以纪念，不能把它当作自己的召唤物或经验仓库 |
| 服务器重启 | 未到期事实恢复；已领取、已耗散和已消耗预算不回滚 |

P1 只有墓碑与幽魂时称“痕迹闭环”，不能宣布以上完整玩法已经完成。P2 满足上表后才是首个完整死亡后果玩法。P3/P4/P5 分别补齐演化、独立 NPC 与正式天命竞争。

## 14. 明确不做与不能假装已做

首版不做全世界生死元素模拟、跨服持久 AI、每玩家可控幽魂、掉装备捡尸、自由碑文编辑、玩家吞吃尸体养成、死亡排行榜、灵魂抽卡商店、虚影装备打造或大模型实时裁决。

技术上不创建第二个世界、不把虚影塞进普通玩家连接表、不把原玩家账号当奖励接收者、不把经验球伪造为物品 ID，也不把历史计划的接口名称当作已存在的代码。

**最终要形成的不是一条“死亡—刷魂—升级”的生产链，而是一个会承认发生过什么、并让后来者遇见其后果的世界。**
