# 五步可玩故事设计范式

> 状态：今后可复用的原创设计方法。本文记录方法；港口巨像的当前故事精要另见[《港口巨像开场_故事精要》](港口巨像开场_故事精要.md)。故事与方法均不代表场景、机制或开场已经实现，也不替换当前开发计划。
>
> 适用范围：开场、短场景、任务片段和世界事件。目标是让玩家在实际跑、跳、攻击、观察和选择中经历因果，而不是先听完故事再被动执行按钮。

## 1. 核心范式

一个可玩的故事，最小单位不是一段对白，而是一条玩家能够理解并亲手改变的因果链：玩家先有明确意图，遇到能读懂的阻碍，尝试改变处境，行动带来新的信息或视角，最后抵达一个与最初预想不同、但由前面行动造成的结果。

必须完整保留的五句话：

1. **我想完成一件事；**
2. **眼前有个障碍；**
3. **我尝试改变它；**
4. **改变带来一个意外；**
5. **我因此抵达了一个与最初预想不同的结果。**

这里的“意外”不等于玩家引发灾难。它可以是行动后获得的新视角、新理解、被揭开的世界事实，或原本看不清的关系突然成立。关键是意外必须由行动和此前可观察的线索共同支撑，不能凭空播放固定高潮。

五步也不是五个按键触发器，更不是把玩家经历机械切成五段脚本。一步可能包含多次操作，也可能因不同的合法路径以不同顺序出现；稳定的是可理解的因果，不是固定的按键和镜头。

## 2. 设计时要保证的因果

| 步骤 | 玩家应能回答的问题 | 设计要求 |
| --- | --- | --- |
| 我想完成一件事 | “我现在想做什么？” | 目标要具体、可见、足够近，让玩家愿意自己走过去；不要先用长对白替玩家赋予抽象使命。 |
| 眼前有个障碍 | “为什么还不能直接完成？” | 障碍要在空间、材质、人物行动或结果上可读；它应限制当前处境，而不是突然弹出一道只认任务状态的门。 |
| 我尝试改变它 | “我怎样做？” | 跑、跳、攻击、绕行、等待或观察等操作必须真的改变位置、结构、关系或信息；提示只帮助理解，不代替行动。 |
| 改变带来一个意外 | “刚才的行动让我发现了什么？” | 意外应是行动造成的新视角或事实，不必是惩罚；先前的震动、环境变化、人物反应等线索要在事后能够串起来。 |
| 我因此抵达了不同结果 | “做完以后，哪里不一样？” | 结果应改变当前道路、认识、关系或下一步问题，并保留玩家确实参与过的事实；不要用未发生的贡献冒充玩家经历。 |

每一步都要让玩家能说清三件事：我为什么想做、我怎样做、做完改变了什么。若只能靠设计者解释，说明故事还没有发生在操作里。

## 3. 可玩故事的边界

### 3.1 紧张来自“还差几步”，不只来自惩罚

温馨、奇异的世界也可以有张力。张力可以来自玩家想看见的事正在靠近、同行者已经走远一点、道路暂时不通、一个声音越来越近，或一个现象即将揭开。它不必依靠追逐、打劫、反派毁灭世界或反复死亡。

第一分钟的目标是顺利游玩的节奏，不是倒计时。慢反应、无操作或误操作的玩家仍应能继续理解世界；失败可以改变路线、位置或视角，但不应取消参与资格或制造软锁。

### 3.2 操作必须有意义

跑、跳和攻击不能只是把角色送到下一个触发区。每个关键操作都至少应改变一项真实情况：

- 跑：接近目标、跟随行动中的人、赶上正在发生的事，或获得更好的观察位置；
- 跳：跨过真实落差，改变所处高度，或选择另一条仍可继续的路线；
- 攻击：对可破坏或可切断的对象产生真实影响，改变道路或他人的行动；
- 观察与等待：让已存在的世界事实变得可理解，而不是替玩家偷偷完成阻塞。

提示不应把“按键”当作故事本身。应先让玩家看见可理解的关系，再在需要时给出操作帮助；攻击教学要等到攻击确实能改变眼前的障碍后出现。

### 3.3 意外要被线索支撑

意外可以推翻玩家的猜测，但不能推翻世界已经展示的事实。玩家事后应能回想：震动、环境变化、人群行动或材料受力，原来都在说明同一件事。这样惊奇会变成理解，而不是“镜头替我宣布答案”。

### 3.4 不把方法做成固定脚本

设计师可以规定材料、地形、人物目标和世界规则，但不要只规定“玩家按下某键后播放某段故事”。合法替代路径可以成立；玩家提前抵达、绕开中间步骤或用另一种有效作用改变障碍时，结果仍应符合世界规则。不同路径可以带来不同观察角度，但不必为每条路径建立一套独立剧情处理器。

## 5. 节奏、容错与世界独立行动

### 5.1 教学节奏不等于世界实体时钟

按玩家的行动推进教学：先让玩家理解目标与障碍，再在操作确实能改变处境时展示提示。提示节奏服务于理解。

场景实体、人物与环境变化按世界规则独立行动。不能为了等玩家按键而冻结世界实体，也不能在玩家未操作时偷偷修改真实事实制造高潮。教学提示可以等待、重复或转移到安全点，世界推进和教学提示的节奏保持分开。

### 5.2 失误改变路线，不取消参与

- 跌落应落到有出口的下层路，能继续前进或返回尝试点；
- 错过关键近景应有后续观景点、远景或可再次理解的线索；
- 慢反应或无操作不应反复死亡、卡在唯一通路或失去全部故事信息；
- 合法替代路径可以到达同一片自由区，不要求所有人按同一动作序列完成；
- 没有软锁时，提示应留在现场，安全停留点应允许玩家重新观察。

### 5.3 同行者与帮助

同行者可以先走到下一个安全点，但不能因为玩家走神就让教学不可追上。需要重复的信息应通过人物停留、动作示范、环境状态或可随时查看的操作帮助保留，而不是强迫玩家重播整段开场。

玩家可以跳过具体开场段落直接到自由探索区；帮助入口仍可随时查看。跳过只改变玩家的观看与教学经历，保留世界事实与玩家实际参与记录。

## 6. 通用审查三问

在加入伏笔、意外、远景、音乐升级或更大的地标之前，逐步审查：

1. 玩家能否说清“我为什么想做”？
2. 玩家能否说清“我怎样做”？
3. 玩家能否说清“做完改变了什么”？

三问成立后，再检查意外是否由行动产生、结果是否与最初预想不同、失误是否仍可继续、世界是否没有被偷偷改写。这样起承转合才是玩家亲手经历的过程，而不是旁白替玩家总结的一段故事。
